# B02 - Participio Passato

## Core Idea
Participio passato is the Italian V3.

## Forms
- `parlare -> parlato`
- `vedere -> veduto / visto`
- `finire -> finito`
- `fare -> fatto`
- `dire -> detto`
- `scrivere -> scritto`
- `aprire -> aperto`

## Examples
- `un lavoro fatto`
- `una porta aperta`
- `una lettera scritta`

## Watch Out
As an adjective it agrees: `porta aperta`, `libri letti`.
