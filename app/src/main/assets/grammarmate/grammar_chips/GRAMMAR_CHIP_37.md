# B21 - Extended Negation

## Core Idea
Italian often uses `non` plus another negative word.

## Patterns
- `non ... niente`
- `non ... nessuno`
- `non ... mai`
- `non ... più`
- `non ... ancora`
- `né ... né`

## Examples
- `Non so niente.`
- `Non è venuto nessuno.`
- `Non fumo mai.`
- `Non lavoro più lì.`

## Watch Out
Double negation is normal in Italian.
