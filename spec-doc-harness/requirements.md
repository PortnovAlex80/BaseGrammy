# Требования

Контракты текущего продукта и исправления подтверждённых дефектов. Существующие ID сохранены. REQ-19 добавляет воспроизводимость сборки; не включает новые продуктовые режимы. Исполнение проверок отмечается отдельно в [приёмке](acceptance.md) и [регрессионных доказательствах](regression-evidence.md).

|---|---|---|---|
| REQ-01 | RestoreDONE доVM; permissions/SAF отказ не вечныйstartup. | UI-01 | FN-01 |
| REQ-02 | Смена пакета, языка или урока очищает ввод и временное состояние; загружает только checkpoint выбранного контекста либо начальные значения. Пользовательские настройки сохраняются. | UI-02, UI-11, UI-23 | FN-02, FN-03, FN-08 |

| REQ-11 | Vocab/background сохраняют ratings/marks/position и refresh. | UI-20 | FN-06 |

CSV import/create публикует доступный пользовательский пакет. | UI-25 | FN-02 |
| REQ-14 | Backup проверяет схему каждого файла и полноту современного snapshot до замены. История Pomodoro, background marks/position входят в backup; config/content исключены. Отсутствие файла очищает старое значение только в подтверждённом полном snapshot. Поддерживаемые старые backup читаются совместимо. UI и кеши после restore показывают восстановленный checkpoint без нового credit. | UI-26 | FN-09, FN-08 |

| REQ-16 | Отказ permissions и ошибка download явно отображаются. Завершение загрузки модели старого языка не объявляет текущий язык готовым. | UI-24 | FN-11 |

Старые непривязанные hidden IDs сохраняются без глобального применения. Новые sentence reports различают одинаковые row IDs разных уроков; неподдерживаемое Hide не показывается. Bad reports разделены по pack; reset и eviction соблюдают свой scope, включая auxiliary. Background marks остаются word-keyed. | UI-13, UI-26 | FN-03, FN-08 |
| REQ-18 | Pomodoro/profile/streak имеют собственное состояние. Навигация и restore не являются grading. Повторные автоматические окна записи mastery сохраняют новые изменения. | UI-04 | FN-08 |
| REQ-19 | Штатный wrapper запускается на поддерживаемых платформах; необходимые встроенные assets доступны из Git; build, unit, lint и проверка архитектурных границ выполняются в CI. Поддержка API 24/25 не требует API 26 файловых операций. | — | FN-12 |
