# Приёмка

Полная приёмка каждого пункта пока открыта. Исходный прогон и подтверждённые дефекты описаны в [регрессионных доказательствах](regression-evidence.md). Успешная статическая трассировка, unit test, Compose click test и проверка на устройстве — разные уровни доказательств. Частичная автоматическая проверка не закрывает сразу все positive/cancel/refusal и аппаратные условия пункта.

- [ ] AC-01 / REQ-01 / UC-01: восстановление завершено до создания ViewModel; отказ в разрешениях или отмена SAF не оставляют приложение на экране загрузки. Проверить успешное выполнение, отмену, отказ и отсутствие изменений несвязанных хранилищ и состояния.

- [ ] AC-02 / REQ-02 / UC-02: Pack/language switch не смешивает cards и scoped progress. Проверить positive/cancel/refusal и отсутствие изменений несвязанных stores/state.

- [ ] AC-03 / REQ-03 / UC-03: старые ELITE/VOCAB читаются как HOME без runtime destinations; story/background открываются по действующим маршрутам.

- [ ] AC-04 / REQ-04 / UC-04: Lesson/sublesson/boss completion соблюдает access/progress. Проверить positive/cancel/refusal и отсутствие изменений несвязанных stores/state.

- [ ] AC-05 / REQ-05 / UC-05: ручная навигация оставляет сессию на паузе, очищает ввод и не засчитывает правильный ответ. Проверить границы очереди и отсутствие изменений несвязанных хранилищ и состояния.

- [ ] AC-06 / REQ-06 / UC-06: отправка ответа, подсказка и смена режима ввода различают показ ответа и начисление освоения. Проверить успешное выполнение, отмену, отказ и отсутствие изменений несвязанных хранилищ и состояния.

- [ ] AC-07 / REQ-07 / UC-07: возврат, остановка и завершение учитывают маршрут `returnTo` и открытые Settings. Проверить подтверждение выхода, отмену и отсутствие изменений несвязанных хранилищ и состояния.

- [ ] AC-08 / REQ-08 / UC-08: Settings и Ladder приостанавливают и возобновляют только действующую тренировку. Проверить возврат к той же карточке, смену контекста и отсутствие изменений несвязанных хранилищ и состояния.

- [ ] AC-09 / REQ-09 / UC-09: Daily cursor/block/resume/repeat scoped по pack. Проверить positive/cancel/refusal и отсутствие изменений несвязанных stores/state.

- [ ] AC-10 / REQ-10 / UC-10: Verb/aux deck и return сохраняют scoped progress. Проверить positive/cancel/refusal и отсутствие изменений несвязанных stores/state.

- [ ] AC-11 / REQ-11 / UC-11: Vocab/background сохраняют ratings/marks/position и refresh. Проверить positive/cancel/refusal и отсутствие изменений несвязанных stores/state.

- [ ] AC-12 / REQ-12 / UC-12: reader и quiz разделены; возврат из reader останавливает озвучку; quiz сохраняет фазу и `allCorrect`. Проверить доступные входы, отмену и отсутствие изменений несвязанных хранилищ и состояния; отсутствие входа в quiz не считать успешным прохождением.

- [ ] AC-13 / REQ-13 / UC-13: импорт валидирует manifest и содержимое до изменения установки; отказ и ошибка публикации сохраняют прежние данные. Проверить CSV import/create, отмену SAF, warnings и подтверждение удаления.

- [ ] AC-14 / REQ-14 / UC-14: backup валидирует формат и полноту до замены, исключает config/content, включает все заявленные виды прогресса. Очистка отсутствующих файлов разрешена для подтверждённого полного snapshot. Старые backup совместимы; кеши и UI читают восстановленные значения.

- [ ] AC-15 / REQ-15 / UC-15: Settings соблюдают ограничения числовых полей, правила имени и список допустимых языков интерфейса. Проверить сохранение, отмену, неверный ввод и отсутствие изменений несвязанных хранилищ и состояния.

## Обязательные сценарии исправлений

| AC | Дополнительные условия |
|---|---|
| 02, 04, 08, 15 | Два пакета и два урока: новая сессия получает свои счётчики, восстановленная — свой checkpoint; Settings → смена пакета очищает draft; возврат к той же карточке сохраняет draft; HARD и streak не сбрасываются при навигации |
| 05, 06, 10 | Next/Prev не отмечают shown; Check после Next/Prev записывает ID показанной карточки; банк слов соответствует карточке; Repeat сохраняет batch, Continue исключает выполненные, Reset сохраняет освоение; WORD_BANK не получает mastery |
| 01, 02, 14 | Save → restart → restore → continue восстанавливает выбранные pack/lesson/sublesson/cursor/counters, без новой оценки и credit; другой пакет не меняется |
| 12, 16 | Play после открытия reader → toolbar Back останавливает narration; системный Back тоже. Результат загрузки модели старого языка не меняет готовность нового |
| 13 | Traversal и неверные manifest references отклоняются; отсутствующий/невалидный обязательный CSV сохраняет старую установку; ошибка после начала публикации откатывает файлы и индексы; импортированный CSV виден в pack navigation |
| 14, 18 | Неверная схема YAML/JSON, неполный современный snapshot, пустая произвольная папка отклоняются до изменения; корректные исторические и современные snapshot принимаются; два автоматических окна mastery действительно записывают данные |
| 04, 06, 17 | Два реальных bundled packs и два урока с одинаковым card_2: скрыть A, проверить B; смешанное повторение начисляет освоение источнику A; старые hidden IDs и новые scoped keys проходят backup/restore |
| 11, 14, 17 | Backup/restore сохраняет Pomodoro history и background marks/position; scoped/full reset и eviction охватывают auxiliary store |
| 19 | Stock wrapper version/build, default asset input check, lint и минимальные Android API файловых операций; независимая проверка из Git checkout |

Точные test methods, результаты, оставшиеся ограничения и исходная ревизия перечислены в [журнале](regression-evidence.md). Compose harness проверяет реальные клики компонентов и callbacks, но не заменяет весь Android lifecycle MainActivity.
