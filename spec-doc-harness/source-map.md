Обновлена для исправлений архитектурного ревью от 2026-10-05. Ревизия кода и исполненные проверки указаны в [журнале доказательств](regression-evidence.md). SHA-256 фиксирует байты файлов в проверенной рабочей копии, включая переводы строк; это не заявление об исполнении каждой строки. Пользовательский каталог `artifacts/` не изменялся.

## Границы проверки

- NavHost и AppScreen имеют разное назначение; Settings остаётся overlay. Старые ELITE/VOCAB читаются как HOME без runtime destinations.
- StoryReader использует актуальные ключи content/storyFile/pack для Play и безусловно останавливает narration при toolbar Back; подтверждение конкретных callback-сценариев находится в журнале.
- Полные ключи адаптера TrainingScreen устраняют устаревшее кеширование полей. Первоначально отмеченные canSubmit/progress не читались UnifiedNavigationRow, поэтому это не считается отдельно воспроизведённым пользовательским багом.
- Backup проверяет поддерживаемые структуры и современный manifest до замены; старые снимки не очищают отсутствующие данные. Import journal и rollback backup имеют разные границы восстановления.
- Settings background-controls используют собственные stores; новые виды сохранённых данных должны включаться в backup/reset/invalidation явно.
- JVM/Compose проверки и эмуляторные маршруты не подтверждают физический Bluetooth, реальный микрофон или качество загруженных голосов.
