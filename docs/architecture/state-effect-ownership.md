# State and effect ownership for the shipping learning paths

Date: 2026-09-29. Scope: the six G2 values in the [architecture closure contract](../plans/2026-09-29-architecture-closure-contract.md). This is a source-code ownership trace, not a claim that G2 or the device gate has passed.

`TrainingViewModel.uiState` is a read projection: it combines `_coreState` with the audio, story, vocabulary sprint, daily, flower and boss flows. The ViewModel's [`TrainingStateAccess`](../../app/src/main/java/com/alexpo/grammermate/shared/TrainingStateAccess.kt) bridge writes `_coreState`; the feature coordinators write their own flows. [`TrainingProgressSnapshotSource`](../../app/src/main/java/com/alexpo/grammermate/ui/TrainingProgressSnapshotSource.kt) reads those sources directly when saving, rather than treating a possibly delayed combined emission as a second authority. [`TrainingProgressWriter`](../../app/src/main/java/com/alexpo/grammermate/ui/TrainingProgressWriter.kt) serializes progress/mastery writes and owns the pending-backup request.

| Value or effect | Authoritative owner and live reader | Transition, reset and persistence path |

Card changes clear the input and previous hint/result; pause and a same-card hint preserve the typed input. Language/lesson/pack selection clears or rebuilds the session in `TrainingViewModel`. [`ProgressTracker.saveProgress`](../../app/src/main/java/com/alexpo/grammermate/feature/progress/ProgressTracker.kt) writes the card index, counts, attempts, active time and status to `PackLessonProgressStore`, keyed by pack and lesson. The deck is rebuilt from the selected pack's `LessonStore` content on restore; typed input and revealed answer are transient. |
| Active session time and save checkpoint | [`SessionActiveTimer`](../../app/src/main/java/com/alexpo/grammermate/feature/training/SessionActiveTimer.kt) alone owns the running clock, tick counter and job. `cardSession.activeTimeMs` is the authoritative persisted elapsed value. `TrainingViewModel.sessionTimerMs` is display-only tick output. | `SessionRunner` starts/pauses the timer. Pause writes accumulated time into `cardSession`; every 20 half-second ticks also writes it and invokes the timer-save callback. The callback reaches `TrainingProgressWriter.saveFromTimer`, which captures state before its serialized I/O lane. `ProgressTracker` writes active time to `PackLessonProgressStore`; startup restores pack/lesson progress before constructing the active session. [`ChapterRoadmapController`](../../app/src/main/java/com/alexpo/grammermate/feature/progress/ChapterRoadmapController.kt) and `ChapterRepository` derive chapter cards/progress from the current pack and mastery. [`FlowerRefresher`](../../app/src/main/java/com/alexpo/grammermate/feature/progress/FlowerRefresher.kt) publishes another derived view. | `SessionRunner` emits `RecordCardShow`, `MarkSubLessonCardsShown` and completion events; `TrainingViewModel.handleSessionEvents` passes them to `ProgressTracker`/stores, then refreshes chapter/flower projections. `TrainingViewModel.recordSelfProducedIfEarned` records review only for accepted VOICE/KEYBOARD answers without revealed hint. [`InputMode.countsTowardMastery`](../../app/src/main/java/com/alexpo/grammermate/data/Models.kt) excludes WORD_BANK. Pack switch rebinds pack-scoped stores and recomputes projections; reset paths clear the stores and reload projections. The code anchors are [`MasteryStorePackScopedTest`](../../app/src/test/java/com/alexpo/grammermate/data/MasteryStorePackScopedTest.kt), [`ChapterProgressRulesTest`](../../app/src/test/java/com/alexpo/grammermate/feature/progress/ChapterProgressRulesTest.kt) and pack-selection click tests. |
| Verb saved batch and shown/completed IDs | [`VerbDrillViewModel`](../../app/src/main/java/com/alexpo/grammermate/ui/VerbDrillViewModel.kt) owns the drill selection/session and its `progressMap` cache; [`VerbDrillDeckPlanner`](../../app/src/main/java/com/alexpo/grammermate/ui/VerbDrillDeckPlanner.kt) selects a batch from those inputs. [`GrammarMateApp`](../../app/src/main/java/com/alexpo/grammermate/ui/GrammarMateApp.kt) is the integration owner: its TRAINING callbacks forward accepted and explicit completion actions to the verb ViewModel while invoking runner navigation. The Daily entry is disabled, so [`DailyPracticeCoordinatorReplayTest`](../../app/src/test/java/com/alexpo/grammermate/feature/daily/DailyPracticeCoordinatorReplayTest.kt) is domain evidence, not a reachable-route UI pass. |

## Cross-cutting integration effects

| Effect | Owner and boundary |
|---|---|
| Navigation | [`GrammarMateApp`](../../app/src/main/java/com/alexpo/grammermate/ui/GrammarMateApp.kt) owns `NavHostController`, push/pop/reset helpers, completion-event consumption and route-specific TRAINING callbacks. [`NavBackHandlers`](../../app/src/main/java/com/alexpo/grammermate/ui/navigation/NavBackHandlers.kt) plus destination-local `BackHandler`s handle physical Back. `TrainingViewModel.navigationEvents` is a one-shot request channel; `navigation.currentScreen` is persisted telemetry/compatibility state, not a second back stack. [`AppRoot`](../../app/src/main/java/com/alexpo/grammermate/ui/AppRoot.kt) delays VM construction until restore finishes. |
| Voice launch and Bluetooth route cleanup | UI [`SpeechRecognitionAttempt`](../../app/src/main/java/com/alexpo/grammermate/ui/voice/SpeechRecognitionAttempt.kt) owns each external recognizer launch/result/disposal and closes its lease on cancellation, callback or disposal. [`AudioCoordinator`](../../app/src/main/java/com/alexpo/grammermate/shared/audio/AudioCoordinator.kt) exposes `acquireSpeechRoute`, handles offline ASR and shutdown, while [`SpeechRouteOwner`](../../app/src/main/java/com/alexpo/grammermate/shared/audio/SpeechRouteOwner.kt) serializes microphone/Bluetooth routing and performs connect/disconnect through an idempotent lease. [`SpeechRouteOwnerTest`](../../app/src/test/java/com/alexpo/grammermate/shared/audio/SpeechRouteOwnerTest.kt) is rule evidence; actual headset routing still needs G5 device evidence. |
| General progress, backup and restore | `TrainingProgressSnapshotSource` reads the owning flows; `TrainingProgressWriter` serializes `ProgressTracker.saveProgress`, `MasteryStore.flush` and optional backup. Restore runs before ViewModel construction in `AppRoot`; live store-cache invalidation is handled by `StoreFactory` after restore. This ordering avoids an old in-memory snapshot overwriting restored files. |

## Audit gaps and closure condition

The vocabulary fire bug found in this audit is addressed by deriving completion from the current session's accepted ratings. The new GOOD and previously reviewed AGAIN cases now have focused store/restart regression coverage. A route exit also invokes `exitSession` before refreshing the parent training projection; final route and device gates still need their own evidence.

The verb path has two distinct cursors: the drill batch cursor and the rendered TRAINING card cursor. `GrammarMateApp` explicitly coordinates them for answer, hint/skip and manual navigation. Keep that bridge covered by the real click regression; direct ViewModel-only tests do not establish route wiring. The production Daily route remains disabled, and hardware voice/Bluetooth behavior remains unverified on a device. This inventory supports G2 review but does not close the route and device gates by itself.
