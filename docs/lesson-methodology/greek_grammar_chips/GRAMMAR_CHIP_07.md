# A07 - Ερωτήσεις (Вопросы)

## Суть
Вопрос = утверждение с вопросительной интонацией. Вопросительные слова уточняют тип ответа.

## Формула
Вопросительные слова:
- `ποιος / ποια / ποιο` — кто / какой (согласуется по роду)
- `τι` — что
- `πού` — где / куда
- `πότε` — когда
- `πώς` — как
- `γιατί` — почему / потому что
- `πόσο / πόσα` — сколько
- `από πού / από πού θε` — откуда

Yes/No вопросы: интонация + `μήπως` (разговорное «ли», смягчает вопрос).

Греческий НЕ использует do-support — вопрос = утверждение с подъёмом интонации.

## Примеры
- `Πώς σε λένε;`
- `Πού μένεις;`
- `Τι είναι αυτό;`
- `Πότε έρχεσαι;`
- `Γιατί δεν έρχεσαι;`
- `Μήπως έρχεσαι αύριο;`
- `Πόσο κάνει;`

## Не путать
`γιατί` = и «почему», и «потому что» — контекст решает: `Γιατί;` = «Почему?», `γιατί...» = «потому что...».

`μήπως` — НЕ вопросительное слово, а частица «ли»: `Μήπως έρχεσαι;` ≈ «Ты ведь придёшь?» — мягче прямого вопроса.
