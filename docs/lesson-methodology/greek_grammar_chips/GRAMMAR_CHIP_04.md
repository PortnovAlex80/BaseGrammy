# A04 - Επίθετα (Прилагательные)

## Суть
Прилагательное согласуется с существительным по роду, числу и падежу — тройное согласование.

## Формула
Три группы окончаний:
- `-ος / -η / -ο` (παλιά группа): καλός, καλή, καλό → καλοί, καλές, καλά
- `-ος / -α / -ο` (νέα группа): ωραίος, ωραία, ωραίο → ωραίοι, ωραίες, ωραία
- `-ής / -ιά / -ί`: μικρός, μικρή, μικρό (исключение по первому типу)

Позиция до существительного: `ένας καλός άνθρωπος` (хороший человек — оценка)
Позиция после существительного: `ένας άνθρωπος καλός` (человек хороший по характеру — описание)

## Примеры
- `η ωραία γυναίκα`
- `ο ωραίος άντρας`
- `το ωραίο παιδί`
- `ένας καλός άνθρωπος`
- `ένα καλό φαγητό`
- `οι καλές μέρες`

## Не путать
Прилагательное меняется по ВСЕМ трём родам (в отличие от итальянского — только два).

`ένας μεγάλος άντρας` = «важный человек», но `ένας άντρας μεγάλος` = «человек большого роста». Позиция прилагательного меняет смысл.
