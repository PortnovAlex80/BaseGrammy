# A13 - Συγκριτικά και υπερθετικά (Сравнительная и превосходная степень)

## Суть
Сравнение через `πιο ... από` — универсальный паттерн для всех прилагательных.

## Формула
Сравнительная: `πιο + прилагательное + από`
- `πιο καλός από` — лучше чем
- `πιο μεγάλος από` — больше чем

Превосходная: `ο πιο ...` (определённый артикль + πιο + прилагательное)
- `ο πιο καλός` — самый лучший

Литературная превосходная: `-ότατος / -ότατη / -ότατο`
- `ωραίος → ωραιότατος`

Нерегулярные формы:
- `καλύτερος / καλύτερη / καλύτερο` — лучший (разговорная)
- `χειρότερος / χειρότερη / χειρότερο` — худший
- `μεγαλύτερος` — больший / старший
- `μικρότερος` — меньший / младший

## Примеры
- `Είμαι πιο ψηλός από εσένα.`
- `Αυτό είναι καλύτερο από εκείνο.`
- `Ο Γιάννης είναι ο πιο ψηλός στην τάξη.`
- `Η Μαρία είναι νεότερη από τον Γιάννη.`
- `Αυτό είναι το χειρότερο.`

## Не путать
`από` в сравнительной = родительный сравнения (русское «больше КОГО» / итальянское «più...di»), но требует винительный: `πιο ψηλός από τον Γιάννη`.

`καλύτερος` (разговорный) vs `πιο καλός` (нейтральный) — оба правильные, но `καλύτερος` чаще в речи.
