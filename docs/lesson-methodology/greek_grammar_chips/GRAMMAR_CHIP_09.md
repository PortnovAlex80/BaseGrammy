# A09 - Προθέσεις και πτώσεις (Предлоги и падежи)

## Суть
Греческие предлоги всегда требуют винительного падежа. Генитив используется без предлога для принадлежности.

## Формула
Предлоги + винительный:
- `σε` — в / на (место и направление): `στην Αθήνα`, `στο τραπέζι`
- `από` — от / из: `από την Αθήνα`, `από το σπίτι`
- `για` — для / за: `για τον Γιάννη`
- `με` — с: `με τη Μαρία`, `με το αυτοκίνητο`
- `χωρίς` — без: `χωρίς ζάχαρη`

Слияние `σε + артикль`:
- `σε + το = στο`, `σε + την = στη(ν)`, `σε + τον = στον`
- `σε + τα = στα`, `σε + τις = στις`

Генитив без предлога: `του βιβλίου` (книги), `της Μαρίας` (Марии)

## Примеры
- `Πάω στο σπίτι.`
- `Είμαι από την Ελλάδα.`
- `Είναι για τον Γιάννη.`
- `Τρώω με το πιρούνι.`
- `Το βιβλίο του μαθητή.`

## Не путать
`σε + артикль` обязательно сливается: `σε το` → `στο`, нельзя сказать `σε το` раздельно.

Греческий сохраняет падежи (именительный / родительный / винительный / звательный), но предлоги ВСЕ требуют только винительный — в отличие от русского, где предлоги управляют разными падежами.
