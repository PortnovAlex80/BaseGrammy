# A14 - Ρήματα με «να» (Модальные конструкции с «να»)

## Суть
В греческом НЕТ инфинитива. Модальная конструкция = модальный глагол + να + υποτακτική (сослагательное).

## Формула
`Μπορώ να + υποτακτική` — могу (возможность)
`Θέλω να + υποτακτική` — хочу (желание)
`Πρέπει να + υποτακτική` — нужно (необходимость)
`Ξέρω να + υποτακτική` — умею (умение)

Нα = «чтобы/пусть» — частица, заменяющая инфинитив.

Примеры спряжения υποτακτική:
- `μπορώ να φάω` (могу поесть)
- `θέλω να πάω` (хочу пойти)
- `πρέπει να διαβάσω` (нужно прочитать)
- `ξέρω να κολυμπάω` (умею плавать)

Разница: `ξέρω` = умение (навык), `μπορώ` = возможность (обстоятельства).

## Примеры
- `Μπορώ να φάω τώρα.`
- `Θέλω να πάω σπίτι.`
- `Πρέπει να δουλέψω.`
- `Ξέρω να μαγειρεύω.`
- `Δεν μπορώ να έρθω αύριο.`
- `Πρέπει να κοιμηθώ.`

## Не путать
Греческий `να` ≠ русский инфинитив. `Θέλω να πάω` = «хочу пойти» (букв. «хочу чтобы пошёл-бы»), не «хочу идти».

`πρέπει να` = «нужно» (безличное), не «должен» — греческое δεν имеет точного эквивалента «я должен».
