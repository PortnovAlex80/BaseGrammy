# A08 - Υπάρχει / Υπάρχουν (Существование: есть/имеются)

## Суть
Υπάρχει обозначает существование/наличие — отличается от описания свойства через είμαι.

## Формула
`Υπάρχει` — единственное число (имеется)
`Υπάρχουν` — множественное число (имеются)

Отрицание: `δεν υπάρχει / δεν υπάρχουν`
Вопрос: `Υπάρχει; / Υπάρχουν;`

Контраст:
- `Το βιβλίο είναι στο τραπέζι.` (описание известного предмета — нужен артикль)
- `Στο τραπέζι υπάρχει ένα βιβλίο.` (наличие нового предмета — неопределённый артикль)

## Примеры
- `Υπάρχει εστιατόριο εδώ κοντά;`
- `Δεν υπάρχει πρόβλημα.`
- `Υπάρχουν πολλά βιβλία.`
- `Στο τραπέζι υπάρχει ένα ποτήρι.`
- `Δεν υπάρχουν πολλές επιλογές.`

## Не путать
`υπάρχει` = «имеется/есть» (существование), `είναι` = «есть/является» (описание). `Υπάρχει νερό;` = «Есть вода?» (существует ли), `Το νερό είναι κρύο` = «Вода холодная» (свойство).

Артикль — индикатор: определённый при `είναι`, неопределённый при `υπάρχει`.
