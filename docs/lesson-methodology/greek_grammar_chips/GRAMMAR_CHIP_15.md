# A15 - Ευγενικές φράσεις (Вежливые фразы)

## Суть
Формулы вежливости для survival-уровня — готовые фразы, которые нужно знать как есть.

## Формула
Приветствие / Прощание:
- `Γεια σου!` — привет (на «ты»)
- `Γεια σας!` — привет / до свидания (на «Вы» и для группы)

Вежливые слова:
- `Παρακαλώ` — пожалуйста / прошу
- `Ευχαριστώ` — спасибо
- `Συγνώμη` — извините
- `Με συγχωρείτε` — извините меня

Просьбы:
- `Θα ήθελα ...` — я бы хотел (формула из θα + imperfect)
- `Μπορείτε να ...;` — можете ли вы...?
- `Μήπως μπορείτε να ...;` — не могли бы вы...?

Другие:
- `Καλή όρεξη!` — приятного аппетита (букв. «хороший аппетит»)
- `Καλή μέρα!` — хорошего дня
- `Να σου συμβουλεύσω ...` — позволь посоветовать
- `Αν μου επιτρέπετε` — если позволите

## Примеры
- `Θα ήθελα έναν καφέ, παρακαλώ.`
- `Γεια σας! Τι κάνετε;`
- `Συγνώμη, πού είναι η τουαλέτα;`
- `Ευχαριστώ πολύ.`
- `Καλή όρεξη!`
- `Με συγχωρείτε, μήπως μπορείτε να με βοηθήσετε;`

## Не путать
`Γεια σας` = и «здравствуйте», и «до свидания» — универсальная формула.

`Θα ήθελα` — даётся как готовая формула (условное наклонение), полная система θα + imperfect будет в B-блоке. Пока не нужно разбирать грамматику — просто запомнить.
