# A03 - Ουσιαστικά: γένος και αριθμός (Существительные: род и число)

## Суть
Три рода существительного управляют согласованием артикля, прилагательного и причастия.

## Формула
Мужской: `-ας` (ο μαθητής), `-ης` (ο εργάτης), `-ος` (ο άνθρωπος)
Женский: `-α` (η μέρα), `-η` (η ζωή), `-ος` (η μέθοδος)
Средний: `-ο` (το βιβλίο), `-ι` (το κορίτσι), `-μα` (το πρόβλημα)

Множественное число:
- `-ος → -οι` (ο άνθρωπος → οι άνθρωποι)
- `-ας/-ης → -ες` (ο μαθητής → οι μαθητές)
- `-α → -ες` (η μέρα → οι μέρες)
- `-η → -εις` (η ζωή → οι ζωές, но многие на -ες)
- `-ο → -α` (το βιβλίο → τα βιβλία)
- `-ι → -ια` (το κορίτσι → τα κορίτσια)
- `-μα → -ματα` (το πρόβλημα → τα προβλήματα)

## Примеры
- `ο μαθητής / οι μαθητές`
- `η μέρα / οι μέρες`
- `το βιβλίο / τα βιβλία`
- `το κορίτσι / τα κορίτσια`
- `το πρόβλημα / τα προβλήματα`

## Не путать
`ο τρόπος` — мужской род на -ος, `η μέθοδος` — женский род на -ος. Окончание -ος бывает всех трёх родов.

`η πόρτα` — женский, хотя оканчивается на -α (не -ος). `το κορίτσι` — средний, не женский.
