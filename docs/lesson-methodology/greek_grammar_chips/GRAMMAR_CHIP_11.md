# A11 - Αριθμοί, ώρα, ημερομηνία (Числа, время, дата)

## Суть
Числа в греческом имеют род. Время и даты используют свои конструкции.

## Формула
Кардинальные: ένα / δύο / τρία / τέσσερα / πέντε / έξι / επτά / οκτώ / εννέα / δέκα
11–19: έντεκα / δώδεκα / δεκατρία / δεκατέσσερα / δεκαπέντε / δεκαέξι / δεκαεπτά / δεκαοκτώ / δεκαεννέα
Десятки: είκοσι / τριάντα / σαράντα / πενήντα / εξήντα / εβδομήντα / ογδόντα / ενενήντα / εκατό

Порядковые: πρώτος / δεύτερος / τρίτος / τέταρτος / πέμπτος

Время: `Τι ώρα είναι; — Είναι τρεις (η ώρα). / Είναι μία. / Είναι δώδεκα.`

Дни недели: η Δευτέρα / η Τρίτη / η Τετάρτη / η Πέμπτη / η Παρασκευή / το Σάββατο / η Κυριακή

Даты: `στις 15 Μαρτίου` (στις + число + генитив месяца)

## Примеры
- `Έχω τρία παιδιά.`
- `Τι ώρα είναι; — Είναι οκτώ.`
- `Σήμερα είναι Δευτέρα.`
- `Γεννήθηκε στις 5 Μαΐου.`
- `Είκοσι ευρώ, παρακαλώ.`

## Не путать
`ένας / μία / ένα` — кардинальное «один» совпадает с неопределённым артиклем и имеет три формы рода.

Дни недели — разный род: `η Δευτέρα` (ж.р.), `το Σάββατο` (ср.р.), `η Κυριακή` (ж.р.).

В датах: `στις` + число + генитив месяца: `στις 15 Μαρτίου`, не `στο 15 Μάρτιο`.
