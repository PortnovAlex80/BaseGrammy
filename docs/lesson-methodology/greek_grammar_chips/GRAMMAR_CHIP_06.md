# A06 - Είμαι vs Έχω (Быть vs Иметь)

## Суть
Быть (είμαι) — для свойств и состояний. Иметь (έχω) — для обладания и физических ощущений.

## Формула
Είμαι + именительный: свойства, профессия, местонахождение.
- `Είμαι κουρασμένος / κουρασμένη / κουρασμένο.`
- `Είμαι γιατρός.`
- `Είμαι εδώ.`

Έχω + винительный: обладание, физические ощущения.
- `Έχω κρύο.` (мне холодно — букв. «имею холод»)
- `Έχω ζέστη.` (мне жарко)
- `Έχω πείνα.` (я голоден)
- `Έχω δίψα.` (мне хочется пить)
- `Έχω δίκιο.` (я прав)
- `Έχω άδικο.` (я не прав)

## Примеры
- `Είμαι γιατρός.`
- `Έχω δίκιο.`
- `Έχω κρύο.`
- `Έχω πείνα.`
- `Είμαι εδώ.`
- `Έχω χρόνο.`

## Не путать
Русское «мне холодно» (дательный) → греческое `έχω κρύο` (винительный). Параллель с итальянским `ho freddo`.

`έχω δίκιο` = «я прав» (не «у меня есть правда»). `έχω ανάγκη` = «мне нужно» (не «у меня есть необходимость»).
