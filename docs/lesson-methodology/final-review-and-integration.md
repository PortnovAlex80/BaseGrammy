# Финальный разбор критики и интеграция правок

## Оценка по существу

Критика обоснована на ~85%. Все четыре ключевых замечания касаются реальных конфликтов зависимостей, а не косметики. Я согласен с их сутью, но соглашаюсь и со смягчением формулировок в нескольких местах.

## Разбор по пунктам

| Замечание | Моя оценка | Принять? |
|-----------|------------|----------|
| non...mai рано (A12), non...ancora к PP (B03), остальное в B21 | Полностью обоснованно. Без non...mai на A1 — речь искусственно «позитивная». Разнесение по урокам логично. | ✅ ПРИНЯТЬ полностью |
| Развести A14 / B13 / B16 по типам инфинитива (чистый / возвратный / с местоимением) | Критично для генерации. Сейчас три разные механики могли смешаться. | ✅ ПРИНЯТЬ полностью |
| A05 — только Indicativo Lei, без императива | Верно. Императив Lei = форма Congiuntivo, давать в A05 преждевременно. | ✅ ПРИНЯТЬ |
| A16 — уточнить, что Imperativo Lei = форма Congiuntivo | Полезное уточнение, готовит почву к B25. | ✅ ПРИНЯТЬ |
| B18 / B20 — развести Gerundio Passato и Participio Assoluto | Идея верна, но формулировка «обязан совпадать» / «антипод» — слишком жёсткая. Смягчить. | ✅ ПРИНЯТЬ со смягчением |
| C05 — усилить про обстоятельства | В текущем плане это уже есть. Не правка, а просто акцент. | ⚪ ОСТАВИТЬ как есть |
| «Структура 10/10» | Самопохвала, не правка. | ⚪ ИГНОРИРОВАТЬ |

### Что важно понимать

Эти правки не меняют архитектуру курса — они делают её герметичной для машинной генерации. Без них агент при создании предложений мог:

- Делать неестественно позитивные фразы на A1–A2 (без non...mai)
- Смешивать voglio mangiare / devo alzarmi / devo farlo в одном уроке
- Вытащить Parli! в A05 раньше времени

После правок каждый урок имеет чёткую границу разрешённых конструкций — это и есть инструкция для генератора.
