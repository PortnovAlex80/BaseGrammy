# Agent 4: Block B (B10-B27) Comparison

## Methodology

- **Old ZIP pack**: 7 lesson files (`it_lesson_01.csv` through `it_lesson_07.csv`) with 1082 total data rows. Old lesson titles: Presente, Routine Giornaliera (Riflessivi), Imperfetto, Passato Prossimo, Futuro+Remoto, Condizionale+Mix, Tutti i Tempi.
- **New plan**: 18 focused lessons (B10-B27), each targeting a single grammar topic. Files `lesson_26_B10.csv` through `lesson_43_B27.csv`.
- Old lessons are organized by tense/mood; new lessons are organized by grammar point. Many B10-B27 topics have **no direct equivalent** in the old pack.
- Sentence counts below are data rows (excluding header).

- **Total new sentences in B10-B27**: 661
- **Total old sentences covering these topics**: ~81 (mostly incidental pronouns in lessons 04/06/07, plus riflessivi in lesson 02)
- **Expansion factor**: 8.2x
- **Lessons that are ENTIRELY NEW** (zero old coverage): B10, B12, B14, B15, B16, B17, B18, B19, B20, B21, B22, B23, B24, B25, B26, B27 = **16 of 18 lessons**
- **Lessons with partial old coverage**: B11 (Pronomi Diretti) — old had ~15 incidental sentences; B13 (Riflessivi) — old had 64 present-tense-only sentences

### Key observations

1. **The old ZIP pack has massive grammar gaps for B-level topics.** Of the 18 grammar points in B10-B27, only 2 (direct pronouns, riflessivi) have any representation in the old pack, and even those were unsystematic. 16 topics (89%) are completely absent from the old pack.

2. **The old pack was essentially a verb-tense drill.** Old lessons are organized around tenses (Presente, Imperfetto, Passato Prossimo, Futuro) with vocabulary sprinkled in. The new plan systematically covers: pronoun system (B11-B16), gerundio system (B17-B19), Congiuntivo system (B25-B27), passive/impersonal (B23), connectors (B24), extended negation (B21), relative pronouns (B22), and Condizionale Composto (B10).

3. **B13 (Riflessivi) is the only lesson with MORE old content.** Old lesson 02 had 64 riflessivi sentences vs new B13's 40. However, the new lesson covers 3 tenses (present, PP, modal+reflexive) while old covered only present tense with 13 different verbs. New trades breadth for depth in tense coverage, which aligns with the course's building-block philosophy.

4. **Sentence quality in new lessons is markedly more focused.** Old lessons frequently mix grammar topics within a single lesson (e.g., lesson 04 mixes PP with Imperfetto, pronouns, and present tense). New lessons have clean single-topic focus. The minimal-pair approach in B25 (fact vs opinion) is methodologically sophisticated and absent from the old pack.

5. **Pronoun progression is completely new and systematic.** B11 (direct) -> B12 (indirect) -> B14 (ci/ne) -> B15 (combined) -> B16 (position with modals/gerund/imperativo) forms a 5-lesson arc that builds logically. The old pack had no pronoun progression at all.

6. **Congiuntivo coverage (B25-B27) is entirely new and substantial.** 129 sentences across 3 lessons (45 + 42 + 42). The old pack had zero Congiuntivo forms. This is the single biggest grammar gap in the old pack.

7. **B10 (Condizionale Composto) addresses a critical Russian-speaker need.** The "future in the past" function (Ha detto che sarebbe venuto) is a systematic error point for Russian speakers, and the old pack had zero coverage. The new lesson dedicates 20 of 39 sentences to this function specifically.
