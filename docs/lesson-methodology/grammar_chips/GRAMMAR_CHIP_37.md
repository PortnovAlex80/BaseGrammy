# B21 - Extended Negation

## Суть
В итальянском часто используется `non` плюс другое отрицательное слово.

## Шаблоны
- `non ... niente`
- `non ... nessuno`
- `non ... mai`
- `non ... più`
- `non ... ancora`
- `né ... né`

## Примеры
- `Non so niente.`
- `Non è venuto nessuno.`
- `Non fumo mai.`
- `Non lavoro più lì.`

## Не путать
Двойное отрицание — норма в итальянском.
