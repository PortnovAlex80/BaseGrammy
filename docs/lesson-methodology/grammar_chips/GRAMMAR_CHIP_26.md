# B09 - Condizionale Semplice

## Суть
Выражения "бы хотел", вежливые просьбы, советы, гипотетические результаты.

## Формулы
- `vorrei`
- `potrei`
- `dovrei`
- `sarei`
- `avrei`

## Примеры
- `Vorrei un caffè.`
- `Potrei venire domani.`
- `Dovresti studiare.`
- `Sarei felice.`

## Не путать
A15 дал формулы. B09 даёт систему.
