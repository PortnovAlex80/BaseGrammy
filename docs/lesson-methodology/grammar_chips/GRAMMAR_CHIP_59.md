# C16 - Alterati

## Core Idea
Altered nouns add size, affection, or attitude.

## Common Suffixes
- `-ino / -ina` - small or affectionate
- `-etto / -etta` - small, softer
- `-one / -ona` - big
- `-accio / -accia` - negative tone

## Examples
- `casa -> casetta`
- `libro -> libretto`
- `ragazzo -> ragazzino`
- `problema -> problemone`

## Watch Out
Meaning is emotional, not only physical size.
