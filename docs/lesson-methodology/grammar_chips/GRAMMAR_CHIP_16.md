# A16 - Imperativo

## Суть
Команды, просьбы, предложения «давай». Формы tu/voi/noi/Lei.

## Правило образования
- **tu**: основа глагола. Для -are инверсия: parla (не parli). Для -ere/-ire = как indicativo: scrivi, dormi
- **voi**: = 2 л. мн.ч. indicativo: parlate, scrivete
- **noi**: = 1 л. мн.ч. indicativo: andiamo, facciamo = «давай пойдём!»
- **Lei**: = Congiuntivo Presente: Parli!, Venga!, Legga! (первый «след» Congiuntivo)

## Отрицание
- tu: `non + инфинитив` — `Non parlare!` (не *Non parla!)
- voi/noi/Lei: `non + императив` — `Non parlate!`, `Non andiamo!`

## Примеры
- `Parla più forte!` (Говори громче! — tu)
- `Non parlare!` (Не говори! — tu отрицание)
- `Scrivi il tuo nome.` (Напиши своё имя — tu)
- `Andiamo!` (Пойдём! / Давай пойдём! — noi)
- `Facciamo una pausa.` (Давайте сделаем перерыв — noi)
- `Parlate più lentamente.` (Говорите медленнее — voi)
- `Non fate rumore!` (Не шумите! — voi)
- `Mi dica.` (Слушаю вас / Скажите — Lei)
- `Legga questo documento.` (Прочитайте документ — Lei)
- `Non si preoccupi.` (Не волнуйтесь — Lei)

## Не путать
Отрицание tu = `non + инфинитив` (Non parlare!), не форма императива (не *Non parla!).
Lei-форма = Congiuntivo Presente — это первый «след» Congiuntиво. Почему Parli! а не Parла!? Потому что для Lei мы «переключаемся» на Congiuntivo. Теория — в Блоке B.
Местоимения с императивом (dammi, prendilo) — в B16.
