# A09 - Preposizioni

## Суть
Предлоги показывают отношения: чей, кому, где, откуда, с кем, для кого.

## Основные
- `di` - принадлежность, тема: `il libro di Marco`
- `a` - направление, адресат: `vado a scuola`
- `da` - откуда, к человеку: `vengo da Roma`, `vado dal dottore`
- `in` - страна/место: `in Italia`, `in ufficio`
- `su` - на: `sul tavolo`
- `con` - с: `con un amico`
- `per` - для: `per te`

## С артиклем
- `a + il = al`
- `di + il = del`
- `in + il = nel`
- `su + il = sul`

## Примеры
- `È il libro del mio amico.`
- `Vivo in Italia.`
- `Il telefono è sulla sedia.`
- `È per me.`

## Не путать
Учить не "перевод предлога", а смысл отношения.
