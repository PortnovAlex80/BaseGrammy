# B02 - Participio Passato

## Суть
Participio passato — это итальянская форма V3.

## Формы
- `parlare -> parlato`
- `vedere -> veduto / visto`
- `finire -> finito`
- `fare -> fatto`
- `dire -> detto`
- `scrivere -> scritto`
- `aprire -> aperto`

## Примеры
- `un lavoro fatto`
- `una porta aperta`
- `una lettera scritta`

## Не путать
Как прилагательное согласуется: `porta aperta`, `libri letti`.
