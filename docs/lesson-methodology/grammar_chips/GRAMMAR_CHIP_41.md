# B26 - Congiuntivo Presente: Irregulars

## Суть
Распространённые формы congiuntivo presente — неправильные.

## Основные формы
- `essere -> sia`
- `avere -> abbia`
- `andare -> vada`
- `venire -> venga`
- `fare -> faccia`
- `dire -> dica`
- `potere -> possa`
- `dovere -> debba`
- `sapere -> sappia`

## Примеры
- `Voglio che tu sia qui.`
- `Spero che lei venga.`
- `Bisogna che tu lo faccia.`

## Не путать
Некоторые формы множественного числа совпадают с indicativo: `che siamo`, `che possiamo`.
