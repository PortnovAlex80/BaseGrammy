# A04 - Aggettivi

## Суть
Прилагательное согласуется с существительным.

## Формы
- `bello, bella, belli, belle`
- `grande, grandi`
- `felice, felici`

## Примеры
- `una bella ragazza`
- `bei ragazzi`
- `un libro interessante`

## Не путать
Сначала определи род/число существительного.

`bello` перед существительным работает как артикль: `il ragazzo → bel ragazzo`, `i ragazzi → bei ragazzi`.
