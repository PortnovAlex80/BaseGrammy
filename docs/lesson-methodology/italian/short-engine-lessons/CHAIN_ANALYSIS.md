# Italian Short-Engine — Sequential Chain Analysis
# Каждый урок = один шаг. Показана связь каждого урока с предыдущим.

================================================================================
УРОК 1 · A01 — Presente Indicativo
================================================================================

ТЕМА: Настоящее время, 3 глагола, 6 лиц (я/ты/он/мы/вы/они)

ЛЕКСИКА-ЯДРО (появляется впервые):
  Глаголы: comprare (покупать), andare (идти), fare (делать)
  Существительные: casa (дом), regalo (подарок)

ПАТТЕРНЫ:
  compro una casa     — Я покупаю дом
  vado a casa         — Я иду домой
  faccio un regalo    — Я делаю подарок

ГРАММАТИКА:
  - 1-е спряжение (-are): compr-o/compri/compra/compriamo/comprano
  - Нерегулярные: vado/vai/va/andiamo/vanno, faccio/fai/fa/facciamo/fanno
  - Неопределённый артикль: una casa, un regalo (используется, но не объяснён)

ЗАВИСИМЫЕ МОМЕНТЫ (не объяснены, но использованы):
  una/un — артикль используется, но тема артиклей ещё не пройдена

→ ВЕДЁТ К: A02 раскроет артикли (una/un vs il/la/lo/l')

ЦЕПОЧКА: это нулевой камень — три опорных предложения
  "compro una casa" / "vado a casa" / "faccio un regalo"
  пройдут через ВСЕ 63 урока

УРОК 2 · A02 — Articoli
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A01:
  ✔ Глаголы: comprare (полная парадигма), andare (io/loro), fare (io/loro)
  ✔ Существительные: casa, regalo
  ✗ "una casa" из A01 → ТЕПЕРЬ объяснено: una = неопределённый артикль

ЧТО НОВОГО:
  Существительные: macchina (машина), libro (книга), armadio (шкаф)
  Артикли:
    неопределённый: una casa, un libro, un regalo, un armadio
    определённый:   la casa, il libro, il regalo, l'armadio
  Семантика: "дом (любой)" vs "тот самый дом" → una vs la

ПАТТЕРНЫ:
  Compro una casa   → любой дом       (из A01 — ТЕПЕРЬ понятно почему una)
  Compro la casa    → тот самый дом   (НОВОЕ)
  Compro un libro / il libro           (НОВОЕ — un/il)
  Compro l'armadio                     (НОВОЕ — l' перед гласной)

ЗАВИСИМЫЕ МОМЕНТЫ:
  Множественное число не показано (le case, i libri, gli armadi)

→ ВЕДЁТ К: A03 добавит множественное число

ТРАССА: A01 "compro una casa" (загадочная una) → A02 (una объяснена, la добавлена)

УРОК 3 · A03 — Sostantivi: genere e numero
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A02:
  ✔ Глагол comprare — теперь все 6 лиц + новое лицо: voi (comprate)
  ✔ Все существительные: casa, regalo, libro, armadio
  ✔ Артикли una/un, la/il/l' из A02

ЧТО НОВОГО:
  Множественное число:
    casa → case (ж.р. -а → -е)
    libro → libri (м.р. -о → -и)
    armadio → armadi (м.р. -io → -i)
  Артикли множественного:
    una casa → le case, un libro → i libri, un armadio → gli armadi
  Новое лицо: voi (comprate / compriamo / comprano)

ПАТТЕРНЫ:
  Compri una casa → Compri le case              (A02 единств. → A03 множ.)
  Compro un armadio → Compro gli armadi          (A02 → A03 множ.)

ТРАССА: A01 "compro una casa" → A02 "compro la casa" → A03 "compro le case"

→ ВЕДЁТ К: A04 добавит прилагательные, которым потребуется согласование с родом/числом

УРОК 4 · A04 — Aggettivi
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A03:
  ✔ comprare все лица + вы (comprate)
  ✔ andare (io/lei/loro), fare (io)
  ✔ casa в ед. и мн. числе из A03
  ✔ Артикли: una/la/le/un/i/gli из A01–A03

ЧТО НОВОГО:

ЗАВИСИМЫЕ МОМЕНТЫ:

→ ВЕДЁТ К: A05 добавит Lei (вежливое Вы) + новые глаголы cucinare/pulire

УРОК 5 · A05 — Forma di cortesia (Lei)
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A04:
  ✔ Глаголы: comprare, andare, fare — все 6 лиц
  ✔ Прилагательные: grande (полная парадигма согласования из A04)
  ✔ casa, macchina, armadio, regalo из A01–A02

ЧТО НОВОГО:
  Вежливая форма: tu → Lei (3-е лицо + "Lei")
    vai a casa → Lei va a casa
    compri → Lei compra
  Новые глаголы: cucinare (готовить), pulire (убирать)
    cucini una cena / Lei cucina una cena     (НОВОЕ: cena — ужин)
    pulisci una stanza / Lei pulisce una stanza (НОВОЕ: stanza — комната)
  Новые существительные: cena (ужин), stanza (комната)

ТРАССА:
  A01: vai a casa (ты идёшь)
  A05: Lei va a casa (Вы идёте) ← тот же глагол, другое лицо

  A04: compri una casa grande
  A05: Lei compra una casa grande ← прилагательное из A04 перенесено

→ ВЕДЁТ К: A06 введёт essere/avere — два фундаментальных глагола

УРОК 6 · A06 — Essere vs Avere (состояния)
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A05:
  ✔ Прилагательные из A04: grande, pulito, nuovo, bello
  ✔ Существительные: casa, stanza, cena, macchina, regalo
  ✔ Артикли: la/il/le/i из A02–A03

ЧТО НОВОГО:
  Глаголы: essere (быть), avere (иметь)
  Essere + прилагательное = описание:
    La casa è grande       (A04 grande → теперь как сказуемое)
    La stanza è pulita     (A04 pulito → сказуемое)
    La cena è buona        (НОВОЕ: buono — хороший)
    La macchina è bella    (A04 bello → сказуемое)
    Le case sono grandi    (A03 множ.ч. + A04 прилагательное)
  Avere + существительное = обладание:
    Ho una casa            (A01 casa → "у меня есть дом")
    Ho una macchina nuova  (A04 nuovo → с avere)
  Идиоматические состояния с avere:
    Ho fame / Ho sete / Ho freddo / Ho caldo / Ho sonno
    (НОВОЕ: fame, sete, freddo, caldo, sonno — но caldo/freddo уже из A04!)

ТРАССА СВОРАЧИВАНИЯ:
  A04: una casa grande (определение при существительном)
  A06: La casa è grande (сказуемое) ← прилагательное переехало в позицию после essere

  A04: casa calda (определение)
  A06: Ho caldo (идиома) ← тот же корень, другой смысл

→ ВЕДЁТ К: A07 превратит все эти утверждения в вопросы

УРОК 8 · A08 — C'è / Ci sono
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A07:
  ✔ Все существительные: casa, macchina, armadio, libro из A02
  ✔ Прилагательные из A04: grande, nuovo, piccolo
  ✔ Множественное число из A03: case, libri

ЧТО НОВОГО:
  Экзистенциальная конструкция:
    C'è una casa (ед.ч.) / Ci sono le case (мн.ч.)
  Отрицание: Non c'è una casa / Non ci sono le case piccole
  Вопрос: C'è una casa? / Ci sono le case?
  Согласование: c'è (ед.) vs ci sono (мн.) —呼应 A03 число

ТРАССА:
  A02: una casa / le case      (просто артикли)
  A08: C'è una casa / Ci sono le case  (существование добавлено)

  A03: le case (множественное число)
  A04: case grandi (прилагательное)
  A08: Ci sono le case grandi (всё вместе в экзистенциальной конструкции)

→ ВЕДЁТ К: A09 введёт предлоги — где именно находится то, что "c'è"

УРОК 9 · A09 — Preposizioni semplici e articolate

ЧТО ПЕРЕТЕКЛО ИЗ A08:

  ✔ Прилагательные из A04

ЧТО НОВОГО:

УРОК 15 · A15 — Condizionale di cortesia
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A14:
  ✔ Все 4 модальных: dovere, volere, potere, sapere
  ✔ Все глаголы в инфинитиве: comprare, andare, fare, cucinare, pulire, lavorare, abitare
  ✔ casa, macchina, regalo, cucina

ЧТО НОВОГО:
  Условное наклонение модальных (вежливость):
    voglio → vorrei (хотел бы)
    posso  → potrei (мог бы)
    devo   → dovrei (следовало бы)

  Формы: vorrei/vorremmo/vorrebbero, potrei, dovrei

ТРАССА:
  A14: Voglio comprare una casa    (прямое желание)
  A15: Vorrei comprare una casa    (вежливое желание) ← модальный → условный

  A14: Posso pulire la cucina
  A15: Potrei pulire la cucina     ← могу → мог бы

  A14: Devo cucinare una cena
  A15: Dovrei cucinare una cena    ← должен → следовало бы

  A14: Vogliamo abitare insieme
  A15: Vorremmo abitare insieme    ← хотим → хотели бы

  A09: nella casa nuova (предлог + артикль)
  A15: vorrebbero lavorare nella casa nuova ← всё вместе

УРОК 16 · A16 — Imperativo (tu/voi/noi/Lei)
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ A15:
  ✔ Глаголы: comprare, andare, fare, cucinare, pulire, lavorare
  ✔ casa, macchina, regalo, cucina
  ✔ Lei из A05 (теперь в повелительном: pulisca!)
  ✔ insieme из A09/A14

ЧТО НОВОГО:
  4 формы повелительного:
    tu:   compra! / va! / fai! / pulisci! / cucina!
    voi:  comprate!
    noi:  compriamo! / andiamo!
    Lei:  compri! / pulisca!
  Отрицательный императив: non + инфинитив (НЕ спряжение!)
    Non comprare! / Non pulire! / Non lavorare! / Non andare!
  НОВЫЕ: oggi (сегодня), tardi (поздно), vieni (приходи)

ТРАССА:
  A01: compri una casa (ты покупаешь — изъявительное)

  A05: Lei pulisce una stanza (она убирает)

  A05: vai a casa (ты идёшь)
  A16: va a casa! (иди!) ← но: non andare! (не ходи = инфинитив)

УРОК 21 · B05 — PP vs Imperfetto
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ B04:

УРОК 22 · B06 — Trapassato Prossimo
================================================================================

ЧТО ПЕРЕТЕКЛО ИЗ B05:
  ✔ PP с avere/essere (B03/B04)
  ✔ Имперфект avere/essere: avevo/ero (из B01)
  ✔ famiglia, casa, macchina, cucina

ЧТО НОВОГО:
  Trapassato = avevo/ero (B01 имперфект) + participio (B02)
  = "уже сделал ДО другого прошедшего события"
  Коннекторы: quando + PP (B04) → trapassato в придаточном
  dopo che + trapassato → PP в главном

ТРАССА:
  B03: ho comprato una casa (я купил)
  B06: avevo comprato una casa (я УЖЕ купил к тому моменту) ← имперфект avere + причастие

  B04: è andato a casa
  B06: ero andato a casa (УЖЕ ушёл) ← имперфект essere + причастие

  B05: quando è arrivata (PP), pulivo la cucina (имперфект)
  B06: quando sono arrivato (PP), aveva già cucinato (trapassato)
  ← B05 паттерн УГЛУБЛЁН: теперь не просто фон, а "уже сделал до"

  B05: la cucina era pulita (состояние-имперфект)
  B06: la cucina era pulita perché avevo pulito ← причина (trapassato)

→ ВЕДЁТ К: B07 перейдёт в будущее (futuro semplice)
