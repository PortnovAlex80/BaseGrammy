## Sentence Design Principles

1. **Each sentence = кто + что делает + с чем + где/когда**: Subject + Verb + Object + Circumstance
2. **Expand context progressively**: A01 = simple SVO, later lessons add adverbials, subordinate clauses
3. **Reuse vocabulary from previous lessons**: Every lesson must recycle lemmas from earlier lessons
4. **No grammar from future lessons**: Strict ladder compliance
5. **Hints in parentheses**: Key Italian words/grammar markers for translation support
6. **Format**: `Russian (hints);Italian`

## Example sentence progression for "comprare":

```
A01: Я покупаю дом (compro, casa); Compro una casa
A04: Я покупаю большой новый дом (compro, casa, grande, nuovo); Compro una casa grande e nuova
A09: Я покупаю дом в центре города (compro, casa, nel centro, città); Compro una casa nel centro della città
B03: Я купил этот дом вчера (ho comprato, casa, ieri); Ho comprato questa casa ieri
B11: Я его купил на прошлой неделе (l'ho, comprato, settimana); L'ho comprato la settimana scorsa
B23: Дом был куплен моей семьёй (casa, essere, comprato, famiglia); La casa è stata comprata dalla mia famiglia
C05: Он сказал, что купил дом в городе (detto, che, comprato); Ha detto che aveva comprato una casa in città
```
