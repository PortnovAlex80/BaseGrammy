## A06 - Essere vs Avere (Idioms)

### A06-1: "Ho paura" -- CORRECT
- Source: standard Italian idiom (avere + paura).
- Notes: Standard idiomatic expression. "Avere paura" = to be afraid.

### A06-2: "Ha gioia" -- AWKWARD
- Italian: `Ha gioia`
- Russian: У неё есть радость
- Source: Opera libretti, D'Annunzio literary prose. Not found in everyday spoken Italian.
- Verdict: **AWKWARD** -- Grammatically valid but literary/poetic. Modern Italian prefers "E felice" or "Prova gioia." For a language-learning app at this level, this is an unusual and potentially confusing choice. The AVERE + abstract noun pattern is being overextended.
- Suggested fix: `E felice` or remove from beginner content; if kept, add note about literary register.

### A06-3: "Ho tristezza" -- AWKWARD
- Italian: `Ho tristezza`
- Russian: У меня есть грусть
- Source: Dante Learning, StudySmarter, multiple grammar guides.
- Verdict: **AWKWARD** -- This is NOT a standard Italian construction. Italian uses "Sono triste" (essere + adjective) for sadness. "Ho tristezza" is essentially ungrammatical in everyday Italian; no standard grammar resource lists it.
- Suggested fix: `Sono triste` (essere + adjective pattern).

### A06-4: "Hai colpa" -- CORRECT (marginal)
- Italian: `Hai colpa`
- Russian: У тебя есть вина
- Source: Legal, philosophical, and everyday contexts use "avere colpa" / "non avere colpa."
- Verdict: **CORRECT** but more common in negative ("Non ho colpa") or with "averne colpa." The standalone affirmative is acceptable but slightly formal/legal.
- No fix needed.

### A06-5: "Ho curiosita" -- AWKWARD
- Italian: `Ho curiosita`
- Russian: У меня есть любопытство
- Source: Common with "di + infinitive" ("Ho curiosita di sapere"), but standalone is less natural.
- Verdict: **AWKWARD** as a bare sentence. Normally used with "di" construction or as general quality ("E bello avere curiosita"). Standalone "Ho curiosita" is odd.
- Suggested fix: `Sono curioso` or add context: `Ho curiosita di sapere`.

### A06-6: "Ha stress" / "Ha ansia" -- CORRECT
- Source: Both "avere stress" and "avere ansia" are used in modern Italian.

### A06-7: "Ha vergogna" -- CORRECT
- Source: Standard idiom "avere vergogna" = to be ashamed.

### A06-8: "Abbiamo certezza" -- AWKWARD
- Italian: `Abbiamo certezza`
- Russian: У нас есть certezza
- Source: "Certezza" is more commonly used as an abstract noun ("la certezza del diritto") rather than with "avere" to express a personal state.
- Verdict: **AWKWARD** -- "Siamo certi" (essere + adjective) would be the natural Italian equivalent. "Avere certezza" is not a standard idiomatic pattern like "avere fame/sete/freddo."
- Suggested fix: `Siamo certi` or `Siamo sicuri`.

### A06-9: "Il bambino e malato -- ha la febbre" -- CORRECT
- Source: "Avere la febbre" requires the definite article with illness nouns. This is correctly handled.

### A06-10: "Abbiamo un buon amico" -- CORRECT
- Source: "Buon" before noun is correct (buono -> buon before consonant).
