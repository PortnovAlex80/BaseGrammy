# Short Lexical Grammar Engine — Italian — Контекст проекта

## Идея

Студент учит ТОЛЬКО грамматику. Лексика — нулевая нагрузка.
Знаменательные слова берутся из файла it_content_words_top20.md — curated набор,
образующий семантический кластер: жизнь семьи (дом, кухня, работа, готовка, уборка).
Служебные слова (артикли, предлоги, местоимения, союзы, частицы), а также
базовые глаголы (essere/avere/stare/fare/andare/venire/sapere) и модальные
(dovere/potere/volere) — не ограничены, они естественная часть грамматики.
Каждый урок = одна новая грамматическая структура на уже знакомых словах.
63 урока. 0 новых знаменательных слов. Вся грамматика A1→C2.

## Подход (не дрилл)

Это НЕ тренажёр с многократным повторением. Задача — на ограниченном наборе лексики
ПОКАЗАТЬ инструменты грамматики. 10–20 предложений на урок, демонстрация грамматической
механики, а не дрилл до автоматизма. Студент видит, КАК работает конструкция.

## Лексика знаменательных слов (источник: it_content_words_top20.md)

Глаголы: comprare, pulire, cucinare, abitare, lavorare, partire, arrivare
Существительные: casa, cucina, stanza, famiglia, lavoro, armadio, macchina, libro, regalo, cena, tavolo, fratello, sorella
Прилагательные: grande, bello, nuovo, piccolo, pulito, caldo, freddo, buono
Наречия: spesso, sempre, insieme, tardi, oggi

## Как русский текст указывает артикль

Без маркера = неопределённый, с маркером = определённый:
  «дом»       → una casa / un libro
  «тот самый»  → la casa / il libro
  «та самая»   → la macchina
  «те самые»   → le case / i libri
  «то самое»   → il regalo
НЕ использовать «этот/эта/эти» — это questo, отдельная тема.
Множественное число передаётся формой русского слова: «дом» → «дома», «книга» → «книги».

**Правило множественного числа и артиклей (A01–A08):**
Неопределённый множественный = partitive (delle/dei/degli) — тема A09.
До A09 ВСЕ множественные предложения ДОЛЖНЫ иметь маркер «те самые/та самая/то самое»,
чтобы давать определённый артикль (le/i/gli). Без маркера = неопределённый = нужен partitive,
который ещё не пройден. Исключение: если артикль не нужен (чистое существительное без артикля).

Примеры:
  «те самые дома»  → le case (определённый мн.ч.) — правильно для A01–A08
  «дома» (без маркера) → delle case (partitive) — НЕЛЬЗЯ до A09

Хинт содержит только глагол и существительное без артикля: (compro, casa).

**Правило местоимений-подлежащих (pro-drop):**
Итальянский — pro-drop язык. Подлежащее выражается окончанием глагола, местоимение НЕ пишется.
Русское «я/ты/он/мы/вы/они» определяет форму глагола, но в итальянском местоимение опускается.
Исключение: Lei (вежливая форма, A05) — пишется всегда, чтобы отличить от lui/lei.
Примеры:
  «Я покупаю» → Compro (НЕ Io compro)
  «Он покупает» → Compra (НЕ Lui compra)
  «Я голоден» → Ho fame (НЕ Io ho fame)
  «Вы (вежл.) покупаете» → Lei compra (Lei — исключение, тема A05)

## Правила построения уроков

1. Каждый урок покрывает ТОЛЬКО то, что указано в программе. Ничего лишнего.
2. Строгая иерархия: урок N не может содержать грамматический элемент из урока N+1 или выше.
3. Предложения от простого к сложному внутри урока.
4. Русский текст определяет артикль: «дом» = неопределённый (una/un),
   «тот самый дом» = определённый (la/il/lo). НЕ «этот» — это questo.
5. Хинты НЕ содержат артикли и другие элементы, которые являются темой данного урока.
   Артикль в хинте = только если артикли ещё не пройдены (как клей).
6. Предложения должны иметь смысл. Не «покупаю работу».

## ⚠️ ПРАВИЛО ИЕРАРХИИ (ПОВТОРЕНИЕ 3 РАЗА — ЭТО САМОЕ ВАЖНОЕ ПРАВИЛО)

**ПРАВИЛО 1: Урок N НЕ МОЖЕТ содержать грамматический элемент из урока N+1 или выше.**
Если тема «partitive articles» — в уроке A04, значит в A04 НЕЛЬЗЯ использовать delle/dei.
Если тема «questo» — в уроке A08, значит в A01-A07 НЕЛЬЗЯ использовать этот/эта/эти.
Если тема «предлоги с артиклями» — в A09, значит в A01-A08 НЕЛЬЗЯ использовать del/della/delle/dei.

**ПРАВИЛО 2: Урок N НЕ МОЖЕТ содержать грамматический элемент из урока N+1 или выше.**
Перед написанием каждого предложения — проверить: не использует ли оно конструкцию
из будущего урока? Примеры нарушений: delle/dei в A04 (partitive = A09),
«этот» вместо «тот самый» в A02 (questo = A08), essere в A04 (copula = A05).

**ПРАВИЛО 3: Урок N НЕ МОЖЕТ содержать грамматический элемент из урока N+1 или выше.**
Если сомневаешься — НЕ используй. Лучше упростить предложение, чем нарушить иерархию.
Проверяй КАЖДОЕ предложение против программы (short-engine-course-program.csv) перед сохранением.

## КОРНЕВОЙ ПАТТЕРН (ВСЕГДА ВЕРНУТЬСЯ К ЭТОМУ)

БАЗОВОЕ ПРЕДЛОЖЕНИЕ: "кто-то ПОКУПАЕТ/УБИРАЕТ/ГОТОВИТ/ЖИВЁТ/РАБОТАЕТ дом/кухню/камеру/машину/книгу/подарок"
Это КОРЕНЬ. Каждый урок = МИНИМАЛЬНАЯ вариация этого корня.
Смотреть на A01-A04 как на ЭТАЛОН:
  A01: compro una casa / compri una casa / compra una casa — один глагол, одна фраза, 6 лиц
  A02: compro una casa / compro la casa — артикль меняется
  A03: compro una casa / compro le case — число меняется
  A04: compro una casa grande / compro una macchina grande — прилагательное добавляется

10–15 ПРЕДЛОЖЕНИЙ МАКСИМУМ НА УРОК. НЕ 20.
Лексика — МИНИМАЛЬНОЕ расширение. Смотреть на A01-A04: только comprare + casa/macchina/libro/regalo.
Новые слова — ТОЛЬКО когда тема урока невозможна без них (A06 нужны stanco/fame, A10 нужны fratello/sorella).
Каждый агент ОБЯЗАН прочитать A01-A04 перед созданием урока.

## Пайплайн генерации урока

Для каждого урока выполнять по шагам:

1. **Прочитать программу** — взять тему урока N из short-engine-course-program.csv
2. **Взять лексику** — из it_content_words_top20.md (знаменательные) + свободные служебные
3. **Прочитать 3 предыдущих урока** — понять, какая грамматика уже введена,
   чтобы строить на ней и не повторять
4. **Посмотреть скелет** — взять примеры из shortlexical-grammar-engine.md как ориентир
5. **Написать урок** — 10–20 предложений RU;IT, от простого к сложному
6. **Проверить иерархию** — сравнить каждое предложение с темами из программы
   для уроков N+1 и выше. Если найден элемент из будущего урока — убрать или заменить
7. **Сохранить** — в short-engine-lessons/A01.csv (или B01, C01...)

## Формат урока для приложения

CSV с парами RU→IT, ~20 предложений на урок.
Предложения от простого к сложному.
Знаменательные слова — только из it_content_words_top20.md. Служебные и базовые глаголы — без ограничений.
