# Italian Lesson Methodology — GrammarMate Progressive Drilling

## Core Principle

Each lesson introduces exactly **ONE new grammatical concept**, built on familiar vocabulary and constructions from previous lessons. The student never faces two new things at once.

## Progressive Complexity Model

```
L1: verbs → L2: singular articles → L3: plural + articles → L4: adjective agreement
     ↓              ↓                      ↓                        ↓
  foundation    articles layer       number layer             modification layer
```

Each layer adds exactly one cognitive load level. Previous layers are reinforced, not replaced.

## Established Mechanics

| Mechanic | Signal | Italian |
|----------|--------|---------|
| Definite article | `тот/та/то` (sg), `те` (pl) | il/lo/l'/la, i/gli/le |
| Indefinite article | bare (no marker) sg | un/uno/una/un' |
| Zero article | bare (no marker) pl | no article |

## Content Rules

1. **Hints:** Italian vocabulary only `(nuovo, amico)` — no Russian grammar markers
2. **No `(есть)/(иметь)`:** Removed — unnecessary in Russian
3. **No mechanical questions:** If `È il libro` exists, `È il libro?` is a duplicate — remove
4. **No `questo/questa` as prompt:** Russian "Это" doesn't distinguish forms
5. **Familiar nouns only:** Each lesson reuses vocabulary from L1-L3
6. **Consistent mechanics:** `тот/та/то/те` carries through ALL lessons

## Lesson Sequence (1-16)

### L1 — Presente Indicativo ✅
**NEW:** Present tense conjugation (6 persons)
**Vocab:** parlare, leggere, dormire, andare, fare, avere, essere + 25 nouns
**Format:** `Я читаю книгу (leggo, un libro);Leggo un libro`

### L2 — Articoli singolari ✅
**NEW:** Singular articles (il/lo/l'/la, un/uno/una/un')
**Built on:** L1 vocabulary
**Mechanic:** `тот/та/то` = definite, bare = indefinite
**Format:** `Это та книга (libro);È il libro` / `Это книга (libro);È un libro`

### L3 — Sostantivi plurale ✅
**NEW:** Plural formation + plural articles (i/gli/le)
**Built on:** L1 nouns + L2 articles
**Mechanic:** `те` = definite, bare = no article
**Format:** `Это те мальчики (ragazzi);Sono i ragazzi` / `Это мальчики (ragazzi);Sono ragazzi`

### L4 — Aggettivi ✅
**NEW:** Adjective agreement (gender/number)
**Built on:** L2/L3 nouns and articles
**Patterns:** -o/-a/-i/-e, -e/-i, special bello/buono
**Format:** `Тот новый друг (nuovo, amico);È il nuovo amico`

### L5 — Possessivi ✅
**NEW:** Possessive adjectives (mio/mia/miei/mie, tuo/tua/tuoi/tue, suo/sua/suoi/sue)
**Built on:** L2/L3 articles + L4 adjective agreement pattern
**Mechanic:** `тот/та/то/те` + possessive → il mio amico / la mia amica
**Format:** `Тот мой друг (mio, amico);È il mio amico`

### L6 — Preposizioni articolate ✅
**NEW:** Prepositions + article combinations (al, del, nel, sul, alla, della...)
**Built on:** L2/L3 articles + L1 places/verbs
**Format:** `Я иду в ту школу (a, scuola);Vado alla scuola`

### L7 — Forma di cortesia (Lei) ✅
**NEW:** Formal "you" (Lei = 3rd person singular)
**Built on:** L1 verbs + L4 adjectives
**Drill:** Tu vs Lei pairs for each verb/adjective
**Format:** `Ты говоришь по-итальянски (parli);Parli italiano` / `Вы говорите (вежл., parla);Lei parla italiano`

### L8 — Essere vs Avere (состояния) ✅
**NEW:** Physical/emotional states (ho fame, ho freddo, sono stanco)
**Built on:** L1 avere/essere + L4 adjectives
**Format:** `Я голоден (fame);Ho fame` / `Я устал (stanco);Sono stanco`

### L9 — Questo / Quello ✅
**NEW:** Demonstrative adjectives
**Built on:** L2/L3 articles + L4 adjective agreement
**Note:** Student now knows enough grammar to handle distinctions
**Format:** `Этот мой друг (questo, amico);Questo è il mio amico`

### L10 — Passato Prossimo (essere) ✅
**NEW:** Past tense with essere (andato, stato, venuto)
**Built on:** L1 andare/essere + L4 adjective agreement (participles agree!)
**Format:** `Мальчик пошёл домой (andato, a casa);Il ragazzo è andato a casa`

### L11 — Passato Prossimo (avere) ✅
**NEW:** Past tense with avere (parlato, letto, capito, studiato)
**Built on:** L1 verbs + L10 passato prossimo structure
**Note:** No participle agreement with avere
**Format:** `Я прочитал книгу (letto, libro);Ho letto il libro`

### L12 — Imperfetto ✅
**NEW:** Imperfect tense (parlavo, capivo, leggevo, dormivo)
**Built on:** L1 present tense conjugation patterns
**Contrast:** Imperfetto vs Passato Prossimo usage
**Format:** `Я читал книгу (leggevo);Leggevo il libro`

### L13 — Futuro Semplice ✅
**NEW:** Future tense (parlerò, capirò, leggerò, dormiremo)
**Built on:** L1 infinitive forms
**Format:** `Я прочитаю книгу (leggerò);Leggerò il libro`

### L14 — Pronomi diretti ✅
**NEW:** Direct object pronouns (mi, ti, lo, la, ci, vi, li, le)
**Built on:** L2/L3 nouns → replaced by pronouns
**Format:** `Я прочитал её (letto, la);L'ho letta`

### L15 — Condizionale presente ✅
**NEW:** Conditional mood (vorrei, potrei, dovrei, parlerei)
**Built on:** L1 verbs + L13 future stem
**Format:** `Я хотел бы книгу (vorrei);Vorrei un libro`

### L16 — Imperativo ✅
**NEW:** Imperative mood (parla!, leggi!, dormi!)
**Built on:** L1 conjugation (tu/Lei forms)
**Format:** `Читай книгу! (leggi);Leggi il libro!`

## Vocabulary Pool (L1-L3, used across all lessons)

### People (m/f pairs)
amico/amica, ragazzo/ragazza, uomo/donna, studente/insegnante, ingegnere/medico

### Objects
libro, tavolo, treno, giardino, bagno, cane, chiave, sedia, specchio, anno

### Places
casa, scuola, teatro, mela, colazione, notte, lezione, problema, mano, città

### Verbs
parlare, capire, studiare, lavorare, vivere, leggere, dormire, andare, fare, avere, essere

### Adjectives
nuovo, piccolo, vecchio, alto, pulito, sporco, giovane, felice, forte, interessante, bello, buono

## Experimental: La Casa — Single-Word Progression Package

**Location:** `experimental_la_casa/` (16 files: `casa_01_A01.csv` — `casa_16_A16.csv`)

### Concept

Take **one word** — `casa` (first clear noun in Italian frequency dictionary, position #106) — and trace it through all 16 lessons. Each file shows the same word accumulating ONE new grammatical layer per lesson.

### Why This Matters

- **Proves the methodology:** If one word can carry 16 lessons, the cognitive load per lesson is truly 1 unit
- **Diagnostic tool:** Student who struggles at a specific lesson file isolates exactly which grammar concept is weak
- **Frequency alignment:** Uses the most frequent concrete noun — maximum real-world applicability
- **Minimal pair clarity:** `la casa` / `una casa` / `le case` / `questa casa` / `quella casa` / `la mia casa` / `alla casa` — every distinction is visible on the same base word

### Progression Summary

```
L01: Vado a casa / Torno a casa (present verbs + casa)
L02: la casa / una casa (singular articles)
L03: le case / delle case (plurals)
L04: la casa grande / la casa è bella (adjectives)
L05: la mia casa / la tua casa (possessives)
L06: alla casa / nella casa / dalla casa (preposizioni articolate)
L07: Lei va a casa / La Sua casa (formal register)
L08: La casa è grande / Ho una casa (essere/avere states)
L09: questa casa / quella casa (demonstratives)
L10: Sono andato a casa (past: essere, participle agrees)
L11: Ho pulito la casa (past: avere, no agreement)
L12: Andavo a casa / La casa era grande (imperfect)
L13: Andrò a casa / La casa sarà grande (future)
L14: La vedo / L'ho comprata (direct object pronouns)
L15: Vorrei una casa / Potrei andare a casa (conditional)
L16: Vai a casa! / Pulisci la casa! (imperative)
```
