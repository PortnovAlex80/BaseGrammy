# B17 - Stare + Gerundio

## Суть
Действие происходит прямо сейчас.

## Формула
`sto/stai/sta/stiamo/state/stanno + gerundio`

## Герундий
- `parlare -> parlando`
- `vedere -> vedendo`
- `dormire -> dormendo`

## Примеры
- `Sto mangiando.`
- `Sta scrivendo una lettera.`
- `Stiamo lavorando.`

## Не путать
Не используй это для будущих планов.
