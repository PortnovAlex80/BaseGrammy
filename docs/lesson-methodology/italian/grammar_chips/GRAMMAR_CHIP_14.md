# A14 - Verbi Modali

## Суть
Модальный глагол + чистый инфинитив.

## Формула
`dovere / potere / volere / sapere + infinito`

## Спряжение
| | dovere | potere | volere | sapere |
|---|--------|--------|--------|--------|
| io | devo | posso | voglio | so |
| tu | devi | puoi | vuoi | sai |
| lui/lei | deve | può | vuole | sa |
| noi | dobbiamo | possiamo | vogliamo | sappiamo |
| voi | dovete | potete | volete | sapete |
| loro | devono | possono | vogliono | sanno |

## Sapere vs Potere
- `so nuotare` = умею (навык) — Я научился плавать.
- `posso nuotare` = могу сейчас (возможность) — Вода тёплая, можно войти.

## Примеры
- `Devo lavorare.`
- `Posso venire.`
- `Voglio mangiare.`
- `So cucinare.`
- `Puoi venire?` (Ты можешь прийти?)
- `Deve studiare.` (Он должен учиться)
- `Vogliamo partire.` (Мы хотим уехать)
- `Sa parlare italiano.` (Он умеет говорить по-итальянски)

## Не путать
Без местоимений и возвратных инфинитивов.
`so nuotare` = умею (навык), `posso nuotare` = могу сейчас (возможность). Sapere = умение, potere = возможность.
