# A09 - Preposizioni semplici e articolate

## Суть
Предлоги упаковывают русские падежи в итальянские конструкции.

## Карта предлогов
- `di` (Род.: принадлежность, тема, материал)
- `a` (Дат.: адресат, направление)
- `da` (Род.: происхождение; Твор.: агент)
- `in` (Предл.: место в)
- `su` (Предл.: на)
- `con` (Твор.: с, совместность)
- `per` (цель, бенефициар)

## Слитные (articolate)
Предлог + Артикль = Одно слово:
- `di + il = del`, `di + la = della`, `di + i = dei`
- `a + il = al`, `a + la = alla`, `a + i = ai`
- `in + il = nel`, `in + la = nella`, `in + i = nei`
- `su + il = sul`, `su + la = sulla`, `su + i = sui`
- `da + il = dal`, `da + la = dalla`

## Примеры
- `Vado al cinema.` (a + il)
- `Il libro di Marco.` (принадлежность)
- `Sono nella stanza.` (in + la)
- `Vengo da Roma.` (происхождение)

## Не путать
`in` + город/страна без артикля: `in Italia`, `a Roma` (не *in la Italia).
