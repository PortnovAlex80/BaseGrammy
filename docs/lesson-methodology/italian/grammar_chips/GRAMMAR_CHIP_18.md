# B01 - Imperfetto

## Суть
Imperfetto — это прошедший фон: привычки, описания, состояния и продолжающиеся действия.

## Формула
- `parlare -> parlavo`
- `vedere -> vedevo`
- `dormire -> dormivo`
- `essere -> ero`

## Примеры
- `Da bambino giocavo fuori.`
- `Il tempo era buono.`
- `Leggevo quando sei arrivato.`

## Не путать
Выбирай по функции: фон/повторяемость, а не по русскому виду.
