# A12 - Frequenza e Quantità

## Суть
Наречия частоты и количества + базовая отрицательная частотность.

## Частота
`sempre` → `spesso` → `qualche volta` → `raramente` → `non...mai`

## Количество
`molto` / `poco` / `troppo` / `abbastanza` / `più` / `meno`

## Отрицательная частотность
- `non + глагол + mai` = никогда не
- `non + глагол + più` = больше не

## Позиция
Наречие частоты стоит **после** спрягаемого глагола:
`Mangio sempre la pasta.` (не *Sempre mangio...)
ИСКЛЮЧЕНИЕ: после `essere` — `È sempre felice.`

## Примеры
- `Vado spesso al cinema.` (Часто хожу в кино)
- `È sempre occupato.` (Он всегда занят)
- `Qualche volta leggo.` (Иногда читаю)
- `Ho molto lavoro.` (У меня много работы)
- `C'è poco tempo.` (Мало времени)
- `Non bevo mai caffè.` (Никогда не пью кофе)
- `Non fumo più.` (Больше не курю)
- `Mangio troppo.` (Я слишком много ем)

## Не путать
`non...mai` — нужны ОБА элемента. По-русски «никогда» уже содержит отрицание, по-итальянски — нет.
`molto` перед существительным = прилагательное (`molto tempo`), после глагола = наречие (`mangio molto`).
`troppo` = чрезмерно (негативный оттенок), `molto` = очень (нейтральный).
