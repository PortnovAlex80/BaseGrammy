# A05 - Lei di Cortesia

## Суть
Вежливое `Lei` использует 3-е лицо единственного числа.

## Примеры
- `Come ti chiami?`
- `Come si chiama?`
- `Tu parli italiano?`
- `Lei parla italiano?`
- `Lei è stanco?` / `Tu sei stanco?`
- `Lei ha fame?` / `Tu hai fame?`

## Не путать
Здесь только Indicativo. Вежливые команды будут в A16.
