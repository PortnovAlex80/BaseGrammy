# B11 - Pronomi Diretti

## Суть
Прямые местоимения заменяют прямые дополнения: кто/что, без предлога.

## Формулы
`mi, ti, lo, la, ci, vi, li, le`

## Примеры
- `Vedo Marco -> Lo vedo.`
- `Vedo Maria -> La vedo.`
- `Compro i libri -> Li compro.`
- `Leggo le lettere -> Le leggo.`

## Не путать
В passato prossimo: `L'ho vista`, `Li ho comprati`.
