# B11 - Pronomi Diretti

## Core Idea
Direct pronouns replace direct objects: who/what, no preposition.

## Forms
`mi, ti, lo, la, ci, vi, li, le`

## Examples
- `Vedo Marco -> Lo vedo.`
- `Vedo Maria -> La vedo.`
- `Compro i libri -> Li compro.`
- `Leggo le lettere -> Le leggo.`

## Watch Out
In passato prossimo: `L'ho vista`, `Li ho comprati`.
