# B17 - Stare + Gerundio

## Core Idea
An action in progress right now.

## Form
`sto/stai/sta/stiamo/state/stanno + gerundio`

## Gerundio
- `parlare -> parlando`
- `vedere -> vedendo`
- `dormire -> dormendo`

## Examples
- `Sto mangiando.`
- `Sta scrivendo una lettera.`
- `Stiamo lavorando.`

## Watch Out
Do not use it for future plans.
