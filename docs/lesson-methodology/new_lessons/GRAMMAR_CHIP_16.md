# A16 - Imperativo

## Суть
Imperativo нужен для просьб, команд и предложений "давай".

## Tu
- `-are -> -a`: `ascolta`, `parla`
- `-ere -> -i`: `scrivi`, `leggi`
- `-ire -> -i`: `apri`, `vieni`

Отрицание для `tu`: `non + infinito`
- `Non parlare.`
- `Non venire.`

## Voi
Форма как настоящее `voi`:
- `leggete`
- `ascoltate`
- `aprite`
- `parlate`

## Noi
Значение "давай/давайте":
- `andiamo`
- `mangiamo`
- `iniziamo`
- `facciamo`

## Lei
Вежливая команда:
- `Legga.`
- `Parli.`
- `Entri.`
- `Aspetti.`
- `Scusi.`

## Примеры
- `Apri la finestra, per favore.`
- `Leggete questo testo.`
- `Andiamo a casa.`
- `Parli chiaramente.`

## Не путать
Местоимения с императивом не здесь. Это B16.
