# A07 - Domande

## Суть
Вопросительное слово показывает, какую роль ищем в предложении.

## Карта
- `chi?` - кто?
- `che cosa? / cosa?` - что?
- `a chi?` - кому? о ком?
- `di chi?` - чей? о ком?
- `con chi?` - с кем?
- `dove?` - где? куда?
- `quando?` - когда?
- `come?` - как?
- `perché?` - почему?
- `quanto?` - сколько?

## Примеры
- `Chi sei?`
- `Cosa fai?`
- `A chi telefoni?`
- `Di chi è questo libro?`
- `Dove vai?`

## Не путать
В итальянском нет английского `do`: `Cosa fai?`, не `Do cosa fai`.
