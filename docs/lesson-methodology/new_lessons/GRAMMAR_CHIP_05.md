# A05 - Forma di Cortesia: Lei

## Суть
Вежливое `Lei` использует 3-е лицо единственного числа.

## Формула
- `tu parli` -> `Lei parla`
- `tu capisci` -> `Lei capisce`
- `tu sei` -> `Lei è`
- `tu hai` -> `Lei ha`

## Примеры
- `Come ti chiami?` - Как тебя зовут?
- `Come si chiama?` - Как Вас зовут?
- `Tu parli italiano?`
- `Lei parla italiano?`

## Полезно
- `Come sta?`
- `Da dove viene?`
- `Ha tempo?`
- `Desidera un caffè?`

## Не путать
Здесь только Indicativo. Команды типа `Parli!`, `Venga!` появятся в A16.
