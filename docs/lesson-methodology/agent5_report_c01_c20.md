# Agent 5: Block C (C01-C20) Comparison

## Methodology

The OLD ZIP pack (`IT_VERB_GROUPS_ALL`, v3) contains 7 lessons covering basic-intermediate grammar: Presente (L01), Verbi Riflessivi (L02), Imperfetto (L03), Passato Prossimo (L04), Futuro+Remoto (L05), Condizionale+Mix (L06), Tutti i Tempi (L07). Total: 1,202 sentences.

Block C covers ADVANCED grammar topics (Congiuntivo Trapassato through Stylistics). Most of these topics are entirely absent from the old ZIP pack. Where partial overlap exists (e.g., Passato Remoto forms in L05/L07, basic passive/si in L02), the old pack has at most a handful of accidental matches, not systematic coverage.

## Lesson C10: Si passivante avanzato
- **New file**: lesson_53_C10.csv
- **Old ZIP mapping**: PARTIAL - L02 has si constructions (si chiama, si sveglia) but only reflexive, not passivante/impersonale
- **Sentence count**: Old ~5 reflexive si (not passivante) vs New 40
- **Coverage comparison**: The old ZIP lesson 02 has reflexive "si" (si chiama, si sveglia) but no passivante or impersonale usage. The new lesson provides: impersonal si (In Italia si vive bene, si dice che), passivante with agreement (Questi prodotti si vendono, Queste case si costruivano), negative impersonal (Qui non si fuma), and complex constructions with embedded Congiuntivo (Si dice che sia, Si spera che).

## Lesson C19: Meta-map - Russian cases to Italian constructions
- **New file**: lesson_62_C19.csv
- **Old ZIP mapping**: NONE - entirely new topic
- **Sentence count**: Old 0 vs New 40
- **Coverage comparison**: No meta-linguistic content in the old ZIP. This diagnostic lesson maps Russian case functions to Italian constructions: Nominative (Vedo Marco), Accusative with pronouns (Lo vedo, La vedo, La compro), Dative with a + pronouns (Gli scrivo, Le telefono), Dative+Accusative combined (Gliela do, Me la dice, Glieli mandiamo), Genitive with di + ne (Ne parlo), Locative with in/a + ci (Ci penso, Ci vado), Source with da + ne (Ne esco), Partitive ne (Ne ho tre), piacere as dative structure (Mi piace), avere for states (Ho freddo), Passive as case-shift (Il libro e stato scritto da Marco), Relative pronouns by case (in cui, di cui, da cui, a cui, con cui, per cui).
- **Notable differences**: This is the capstone meta-lesson. It systematically shows each Russian case function paired with its Italian equivalent. The minimal pair structure (full noun -> pronoun) is pedagogically excellent: "Parlo del problema" -> "Ne parlo", "Vado in ufficio" -> "Ci vado". The passive-as-case-shift section is insightful.
- **Gaps**: 40 sentences is tight for covering the full case map. Instrumental case (con/da) is barely represented. The piacere structure gets only 2 sentences. Some case functions from the spec (comitative, temporal) are not explicitly covered.

### Key Observations

1. **Massive expansion**: Block C adds 800 sentences covering 20 entirely new advanced topics. The old pack had essentially zero coverage of these areas.

2. **Sentence count consistency**: Most lessons have exactly 40 sentences (range 38-42). This is below the plan targets (40-70 per lesson) but acceptable for the advanced level where each sentence carries more grammatical weight.

3. **Structural quality**: The best-structured lessons are C01 (Congiuntivo Trapassato), C06 (Concordanza dei Tempi), C09 (Trapassato Remoto), and C19 (Meta-map). These have clear internal sections with progressive complexity.

4. **Underrepresented topics within lessons**:
   - C10: Missing double-si (ci si sveglia)
   - C13: rendersi conto (1 sentence), venire in mente (2 sentences)
   - C16: Last 3 sentences are filler without alterati; no -ello suffix
   - C18: far finta, tenere conto, rendersi conto get only 1 sentence each

5. **Overlap between C14 and C15**: Some connectors (purché, sebbene) appear in both lessons. C14 focuses on meaning, C15 on the Congiuntivo trigger. This is intentional but some connectors (affinche, qualora) appear only in C14, not C15.

6. **Old ZIP structural weakness**: The old pack's "Futuro + Remoto" (L05/L07) is misleadingly titled -- it contains almost no Passato Remoto. Lessons L03/L05 are identical (both Imperfetto), and L04/L06 are identical (both Passato Prossimo). The old pack has significant duplication that the new course structure eliminates entirely.

7. **Quality of new sentences**: Sentences are natural, context-appropriate, and systematically cover the target grammar. The Russian hints use parenthetical vocabulary cues matching the app format. Each sentence is a clean drill item with clear pedagogical purpose.
