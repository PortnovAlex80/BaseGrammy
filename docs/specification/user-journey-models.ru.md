## Путешествие 1: Первый запуск (Холодный старт)

## Путешествие 4: Тренировочная сессия — Карточка за карточкой

### Шаг 4.1: Пользователь видит первую карточку (состояние PAUSED)

| Аспект | Детали |
|--------|--------|
| **Что видит пользователь** | Карточка с русским промптом, область ввода, кнопка Play, кнопки режима ввода (Микрофон/Клавиатура/Книга), стрелка «Далее», иконка «Показать ответ» (глаз) |
| **Состояние сессии** | PAUSED — таймер не запущен, кнопка Check отключена |
| **Доступные действия** | Нажать Play → начать сессию (Шаг 4.2) |
| | Переключить режим ввода → сменить на VOICE/KEYBOARD/WORD_BANK |
| | Нажать «Далее» → перейти к следующей карточке без запуска таймера |
| | Нажать «Показать ответ» → показать ответ |
| | Нажать выход (StopCircle) → показать диалог выхода |
| **Элементы** | TS-01 через TS-37 |
| **Источник спеки** | 19-screen-catalog.md §3, scenario-01 §3 |
| **Расхождение** | Нет |

### Шаг 4.2: Пользователь нажимает Play (PAUSED → ACTIVE)

| Аспект | Детали |
|--------|--------|
| **Действие пользователя** | Нажимает кнопку Play |
| **Ответ системы** | `togglePause()` → `startSession()`: устанавливает sessionState=ACTIVE, запускает таймер, очищает inputText |
| **Что визуально меняется** | Иконка Play → иконка Pause. Таймер начинает тикать. Кнопка Check становится активной (при наличии ввода). Если режим VOICE: распознавание речи запускается автоматически через 200мс |
| **Переход состояния** | `PAUSED → ACTIVE` |
| **Источник спеки** | scenario-01 §3.1 |
| **Расхождение** | Нет |

### Шаг 4.3: Пользователь вводит ответ и нажимает Check

| Аспект | Детали |
|--------|--------|
| **Действие пользователя** | Вводит ответ в режиме KEYBOARD, нажимает кнопку Check |
| **Предусловия** | `sessionState == ACTIVE && inputText.isNotBlank() && currentCard != null` |
| **Ответ системы** | `submitAnswer()` → нормализует ввод → сравнивает с принятыми ответами |

#### 4.3a: Правильный ответ

| Аспект | Детали |
|--------|--------|
| **Что видит пользователь** | Зелёная метка «Correct» (TS-26). Звук успеха |
| **Изменение состояния** | `correctCount++`, `lastResult = true` |
| **Если карточка не последняя**: | Автопереход к следующей карточке через `nextCardInternal()`: очищает ввод, сбрасывает счётчик попыток, загружает новую карточку, таймер продолжает идти |
| **Если карточка последняя**: | Таймер ставится на паузу, `subLessonFinishedToken` увеличивается, автонавигация на LESSON |
| **Источник спеки** | scenario-02 §3 |
| **Расхождение** | **BUG-NAV-002**: После правильного ответа на средней карточке сессия остаётся ACTIVE. Нет визуальной подсказки (пульсирующая стрелка «Далее», автопереход с анимацией), которая сообщает пользователю, что ответ принят и он на следующей карточке. Содержимое карточки меняется, но переход мгновенный и легко незаметен, особенно в режиме VOICE при автоотправке. |

#### 4.3b: Неправильный ответ (попытки 1-2)

| Аспект | Детали |
|--------|--------|
| **Что видит пользователь** | Красная метка «Incorrect». Звук ошибки. Поле ввода очищается (режим VOICE) или остаётся (режим KEYBOARD) |
| **Изменение состояния** | `incorrectCount++`, `incorrectAttemptsForCard++` |
| **Пользователь может** | Ввести новый ответ и повторить. В режиме VOICE: распознавание перезапускается автоматически |
| **Источник спеки** | scenario-02 §4 |
| **Расхождение** | Нет |

#### 4.3c: Неправильный ответ (попытка 3)

| Аспект | Детали |
|--------|--------|
| **Что видит пользователь** | Появляется карточка-подсказка со всеми принятыми ответами, разделёнными « / » |
| **Изменение состояния** | `sessionState = HINT_SHOWN`, таймер ставится на паузу, `incorrectAttemptsForCard` сбрасывается в 0 |
| **Пользователь может** | Нажать «Далее» для перехода (→ Шаг 4.5) или Нажать Play (→ Шаг 4.2b) |
| **Источник спеки** | scenario-02 §5 |
| **Расхождение** | **BUG-NAV-003**: Кнопка Play из HINT_SHOWN вызывает `startSession()`, который устанавливает `sessionState = ACTIVE` и очищает `inputText`, но НЕ очищает `answerText` (текст подсказки). Карточка-подсказка остаётся видимой пока сессия ACTIVE, а кнопка Check снова активна. Пользователь может отправить ответ, пока подсказка всё ещё отображается. |

### Шаг 4.5: Пользователь нажимает «Далее» (любое состояние)

| Аспект | Детали |
|--------|--------|
| **Действие пользователя** | Нажимает кнопку со стрелкой вправо («Далее») |
| **Ответ системы** | `nextCard()`: увеличивает индекс, загружает новую карточку, очищает всё локальное состояние карточки, устанавливает `sessionState = ACTIVE` |
| **Активна когда** | `hasCards` (currentCard != null) — **всегда активна, нет проверки sessionState** |
| **Если был HINT_SHOWN**: | Возобновляет таймер |
| **Если карточка последняя**: | `coerceAtMost(lastIndex)` — остаётся на последней карточке, нет сигнала завершения |
| **Источник спеки** | scenario-01 §3.3 |
| **Расхождение** | **BUG-NAV-004**: Кнопка «Далее» всегда активна, даже во время ACTIVE-сессии. После автоперехода при правильном ответе пользователь может нажать «Далее» и пропустить следующую карточку без ответа. **BUG-NAV-005**: Нажатие «Далее» на последней карточке оставляет на последней карточке без визуальной обратной связи о завершении сессии. Только кнопка Stop/Exit предоставляет путь выхода. |

## Путешествие 5: Битва с боссом

### Шаг 5.1: Сессия босса начинается (PAUSED)

| Аспект | Детали |
|--------|--------|
| **Что видит пользователь** | TrainingScreen с заголовком «Boss Battle» / «Review Session», первая карточка загружена, состояние PAUSED |
| **Доступные действия** | Нажать Play для начала |
| **Отличия от обычной тренировки** | Нет лимита времени (только замер прошедшего времени). Прогресс-бар показывает % завершения босса. Неограниченные попытки |
| **Источник спеки** | scenario-09 §2 |
| **Расхождение** | **BUG-NAV-001** (тот же, что Шаг 3.3) |

### Шаг 5.2: Карточки босса одна за другой

| Аспект | Детали |
|--------|--------|
| **Так же как Путешествие 4** | Play/Pause/Check/Retry работают идентично обычной тренировке |
| **Дополнительно**: | Прогресс-бар босса продвигается с каждой карточкой. Пороги наград: BRONZE >50%, SILVER >75%, GOLD 100% |

### Шаг 5.3: Пауза награды босса

| Аспект | Детали |
|--------|--------|
| **Триггер** | Прогресс босса пересекает порог награды (33/66/100% для BRONZE/SILVER/GOLD) |
| **Ответ системы** | Сессия ставится на паузу, отображается сообщение о награде |
| **Что видит пользователь** | Оверлей награды с названием тира |
| **Действие пользователя** | Закрыть награду → сессия возобновляется |
| **Источник спеки** | scenario-09 §4 |
| **Расхождение** | **BUG-NAV-006**: `clearBossRewardMessage()` имеет сложное условие для `shouldResumeTimer`, читающее `bossActive`, `sessionState`, `currentCard`, `inputMode` в разных точках. Если состояние изменится между чтением и записью, решение о возобновлении может быть устаревшим. |

### Шаг 5.4: Босс завершается

| Аспект | Детали |
|--------|--------|
| **Триггер** | Все карточки босса отвечены (последняя правильно) |
| **Ответ системы** | `finishBoss()`: вычисляет награду, записывает в ProgressStore, восстанавливает предыдущее состояние урока, пересобирает карточки |
