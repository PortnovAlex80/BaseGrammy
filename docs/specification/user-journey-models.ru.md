# Модели пользовательских путешествий — Пошаговая трассировка поведения

> Версия: 1.1 | Дата: 2026-05-16 | Ветка: main
> Назначение: Моделирование каждого пользовательского пути от запуска приложения до завершения функции. Сравнение ожиданий спеки с реальным поведением кода. Расхождения помечаются для исправления.

---

## Принципы проектирования

### ДП-04: Универсальный карточный движок

Все карточные режимы тренировки используют один и тот же UI-движок TrainingScreen. Единственные различия между режимами:
1. **Источник карточек** — какие карточки заполняют `sessionCards` (расписание, пул босса, drill-карточки и т.д.)
2. **Оценка** — считается ли mastery, применяются ли награды босса
3. **Тема** — стандартная тема для всех режимов
4. **Выход** — экран назначения после завершения

Это применяется к 5 подрежимам внутри TrainingScreen: NORMAL, BOSS, BOSS_MEGA, ELITE, DRILL.
Также применяется к 2 отдельным экранам, использующим TrainingCardSession: VerbDrillScreen, DailyPracticeScreen.

Исключение: VocabDrillScreen (механика Anki-карточек — принципиально другой паттерн взаимодействия).

Навигация (Next/Prev/Pause/Play/Exit) ДОЛЖНА быть идентичной во всех режимах. Никаких специфичных для режима функций навигации.

## Общие паттерны поведения

Многие экраны используют одни и те же базовые механики. Паттерны выделены для устранения дублирования и единообразного исправления багов.

### Паттерн A: Тренировка предложений (Sentence Training)

**Базовый поток:** карточка с промптом → выбор режима ввода → Play (старт таймера) → ввод ответа → Check → нормализация → сравнение → результат → следующая карточка.

**Подробные шаги базового потока:**

| Шаг | Действие | Ответ системы |
|-----|----------|---------------|
| A.1 | Пользователь видит карточку | PAUSED: промпт, область ввода, кнопки Play / Check / Next / Show Answer / Exit |
| A.2 | Нажимает Play | `togglePause()` → `startSession()`: sessionState=ACTIVE, таймер запущен, inputText очищен |
| A.3 | Вводит ответ, нажимает Check | `submitAnswer()` → нормализация → сравнение с принятыми ответами |
| A.4a | Ответ правильный | correctCount++, зелёная метка, автовызов `nextCardInternal()` или пауза если последняя |
| A.4b | Ответ неправильный (попытки 1-2) | incorrectCount++, красная метка, retry (VOICE: авто-перезапуск) |
| A.4c | Ответ неправильный (попытка 3) | sessionState=HINT_SHOWN, таймер пауза, показ всех ответов |
| A.5 | Нажимает Next | `nextCard()`: индекс++, новая карточка, sessionState=ACTIVE |
| A.6 | Нажимает Show Answer | `showAnswer()`: пауза, показ ответов, sessionState=HINT_SHOWN |
| A.7 | Нажимает Exit | Диалог подтверждения → `finishSession()` → навигация обратно |

**Используется в:**

| Путешествие | Реализация | Отличия от базового потока |
|-------------|------------|---------------------------|
| Путешествие 4: Под-урок | SessionState enum | Базовая реализация. Все 3 режима ввода (VOICE/KEYBOARD/WORD_BANK). Mastery записывается |
| Путешествие 5: Босс | SessionState enum | Нет лимита времени (только замер). Награды BRONZE/SILVER/GOLD. Неограниченные попытки. BUG: записывает mastery |
| Путешествие 6 Блок 1: Daily Translate | DailyPracticeSessionProvider | 10 карточек. Автопереход 400мс. Режимы VOICE/KEYBOARD/WORD_BANK ротируют |
| Путешествие 6 Блок 3: Daily Verbs | DailyPracticeSessionProvider | 10 карточек. Без VOICE (только KEYBOARD/WORD_BANK). Остальное как Блок 1 |
| Путешествие 7: Verb Drill | CardSessionStateMachine | Без VOICE. Показ инфинитива глагола, ранга, времени на карточке. Автопереход 500мс (гонка BUG-NAV-012) |

### Паттерн B: Оценка карточек (Flashcard Rating)

**Базовый поток:** лицевая сторона (слово) → опциональный голосовой ввод → переворот → обратная сторона (перевод + формы + коллокации) → оценка (Again/Hard/Good/Easy) → SRS-шаг обновлён → следующая карточка.

**Подробные шаги базового потока:**

| Шаг | Действие | Ответ системы |
|-----|----------|---------------|
| B.1 | Пользователь видит лицевую сторону | POS-бейдж, ранг, слово (32sp bold). Кнопки: TTS, Mic, Skip, Flip |
| B.2 | (Опционально) Голосовой ввод | До 3 попыток. Сравнение с синонимами (разделитель «/»). Автофлип при правильном или макс. попытках |
| B.3 | Переворот карточки | Обратная сторона: слово + перевод + формы + коллокации |
| B.4 | Выбор оценки | AGAIN → step=0, HARD → step без изменений, GOOD → step+1, EASY → step+2 |
| B.5 | Автопереход к следующей карточке | Индекс++, загрузка следующего слова |

**Используется в:**

| Путешествие | Отличия от базового потока |
|-------------|---------------------------|
| Путешествие 6 Блок 2: Daily Vocab | SESSION_SIZE карточек. Без фильтров (автовыбор). Без голосового ввода на лицевой стороне |
| Путешествие 8: Vocab Drill | Полная версия. Фильтры: направление (IT→RU / RU→IT), POS, частотность. TTS-кнопка. Skip-кнопка. Голосовой ввод |

### Паттерн C: Асинхронная операция (Async Operation)

**Базовый поток:** действие пользователя → запуск фоновой задачи → индикатор прогресса → завершение → обновление состояния.

**Используется в:**
- Путешествие 9: Импорт пака (синхронный на основном потоке — BUG)
- Путешествие 10: Загрузка TTS (асинхронный с прогрессом)
- Путешествие 11: Бэкап/Восстановление (синхронный без прогресса — BUG)

## Путешествие 4: Тренировка предложений (Под-урок)

> **Основа: Паттерн A — Тренировка предложений.** Базовая реализация. Все 3 режима ввода. Mastery записывается. См. Паттерн A для полного описания базового потока.

### Отличия от базового потока

- Полная реализация Паттерна A — все шаги A.1–A.7 работают как описано
- Все 3 режима ввода: VOICE, KEYBOARD, WORD_BANK
- Mastery: `recordCardShowForMastery()` вызывается при показе каждой карточки
- Завершение: `subLessonFinishedToken` → автонавигация на LESSON

### Выявленные расхождения

| ID | Шаг | Описание |
|----|-----|----------|
| BUG-NAV-002 | A.4a | Нет визуальной подсказки после автоперехода при правильном ответе. Карточка меняется мгновенно без анимации, легко не заметить |

| BUG-NAV-004 | A.5 | Кнопка «Далее» всегда активна — можно пропускать карточки во время ACTIVE-сессии |
| BUG-NAV-005 | A.5 | «Далее» на последней карточке остаётся на ней без обратной связи о завершении |

## Путешествие 5: Битва с боссом

> **Основа: Паттерн A — Тренировка предложений.** Вариация: награды, без лимита времени, неограниченные попытки.

### Отличия от базового потока

- Нет лимита времени — только замер прошедшего времени
- Прогресс-бар показывает % завершения босса
- Пороги наград: BRONZE >50%, SILVER >75%, GOLD 100%
- Неограниченные попытки (нет штрафа за ошибки)
- При пересечении порога награды: пауза, оверлей награды, возобновление после закрытия
- Завершение: `finishBoss()` → вычисляет награду → записывает в ProgressStore → `bossFinishedToken` → LESSON

### Выявленные расхождения

| ID | Шаг | Описание |
|----|-----|----------|
| BUG-NAV-001 | Весь босс | Записывает mastery несмотря на спеку. 3 вызова `recordCardShowForMastery()` без `bossActive`-проверки |
| BUG-NAV-006 | Пауза награды | `clearBossRewardMessage()` — устаревшее чтение состояния в условии `shouldResumeTimer` |
| BUG-NAV-007 | Завершение | Перезапись награды при повторе — GOLD может замениться на BRONZE |
