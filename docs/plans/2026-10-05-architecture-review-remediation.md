# Исправление результатов архитектурного ревью от 5 октября 2026 года

Поручение пользователя: завершить ревью, составить план, реализовать исправления с особым контролем регрессий и отразить новые контракты в `spec-doc-harness`. Исходная ревизия — `a0cf2d866`, результаты — [архитектурное ревью](../architecture/ARCHITECTURE_REVIEW_2026-10-05.md). План принят к исполнению в текущей feature-ветке; merge и push в него не входят.

## Подход

Применяются ограниченные исправления существующего runtime с проверкой каждого исправленного контракта. Решение и рассмотренные альтернативы записаны в [ADR 033](../architecture/decisions/033-review-remediation-boundaries.md). Старые форматы пользовательских данных сохраняются через явные читатели совместимости. Неиспользуемый runtime удаляется после проверки потребителей и тестов.

## Инварианты исправлений

- До первого изменения установленного пакета проверены идентификаторы, пути и обязательное содержимое. Перечень эффектов включает языки, registry, lesson/story/vocab indexes, drills и audio; откат не ограничивается одним каталогом.
- Проверки backup опираются на реальные сериализаторы и поддерживаемые исторические фикстуры. Корректный пустой прогресс отличается от произвольного YAML map. Rollback при исключении и восстановление после остановки процесса описываются отдельно.
- При смене контекста сбрасываются очередь, ввод, результат, hint/retry и счётчики, сохраняются пользовательские настройки. Обычное возобновление той же карточки сохраняет draft.
- WORD_BANK не получает mastery credit. Ручная навигация не отмечает карточки выполненными. Verb Repeat повторяет весь сохранённый batch, Continue исключает выполненные карточки, Reset сохраняет освоение.
- Ошибка import/restore не превращается в «успех» с потерянными данными. UI и кеши после успешного restore читают восстановленный snapshot.
- Миграционные читатели сохранений не удаляются вместе с мёртвыми экранами. Отключённый Daily не включается в продукт в рамках исправления.
- Регрессионные проверки используют реальные публичные операции. Для VerbDrill обязательны клики UI; для Settings pack switch добавляется интеграционный сценарий.
- Дополнительно обнаруженная коллизия CSV IDs закрывается runtime-происхождением карточки и scoped скрытием: другой pack/lesson остаётся видимым, подмешанная карточка начисляет освоение своему уроку. Persisted mastery IDs сохраняются; неоднозначные старые hidden IDs хранятся без глобального применения. Решение внесено в ADR 033.

## Обновление Spec Harness

Сохраняются существующие идентификаторы REQ-01…18, UC-01…18 и AC-01…18. Уточняются условия импорта, reset, backup, audio и pack scope; новые проверки связываются с соответствующими требованиями. Новые независимые требования получают новые ID. `source-map.md` обновляется после стабилизации кода. В `acceptance.md` различаются статическая трассировка, JVM/click tests и device evidence; успешный JVM test не отмечает весь аппаратный сценарий пройденным.
