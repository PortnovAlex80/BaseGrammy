## 1. Суть подводящего упражнения

Сложная итальянская форма (Passato Prossimo, Condizionale Composto и т.д.)
состоит из двух компонентов — опорного (служебного) глагола и смысловой части.
Ученик спотыкается потому, что одновременно решает несколько задач: выбор
вспомогательного + форма причастия + согласование. Внимания не хватает.

**Подводящее упражнение** изолирует **первый (опорный) компонент** и массово
доводит его до автоматизма ДО сборки полной формы. Когда форма
`ho / hai / ha / abbiamo / avete / hanno` перестаёт требовать мысли, весь ресурс
внимания уходит на причастие.

Признаки, отличающие подводящее от обычного Verb Drill:
1. **Массовость** — много повторений одного опорного глагола во всех лицах.
2. **Изоляция** — только опорный глагол, без второго компонента.
3. **Целевая привязка** — рядом указан номер урока, к которому ведёт упражнение.

## 2. Принцип реализации

> **Один источник данных, всё остальное — своё.**

Новый режим — отдельный, полностью изолированный слой (Подход A). Существующий
Verb Drill не меняется ни в одной строке. Это сознательный выбор: дублирование
логики оправдано безопасностью от регресса в боевом режиме.

**Файл-источник один** — физически тот же `it_verb_groups_all.csv` пака.
Копирования данных нет.

### 2.1. Что переиспользуется (общее, без копирования)

Только три «сырые» точки доступа к данным пака:
- `LessonStore.getVerbDrillFiles(packId, lang): List<File>` — получить файлы пула.
- `LessonStore.hasVerbDrill(packId, lang): Boolean` — признак наличия пула (видимость тайла).
- `VerbDrillCsvParser.parse(reader): ParseResult` — парсер CSV.

Парсер вызывается напрямую, результат маппится «на лету» в свой `AuxDrillCard`.
Так файл один, парсер один, а модель живёт своей жизнью.

### 2.2. Что своё (новое, изолированное)

| Компонент | Файл | Назначение |
|-----------|------|------------|
| Модель | `data/AuxDrillCard.kt` | data class; маппится из распарсенного CSV |
| Каталог | `data/AuxDrillCatalog.kt` | статический список пар (verb+tense)→урок |
| Store | `data/AuxDrillStore.kt` | свой прогресс `aux_drill_progress.yaml` + `aux_drill_last_session.yaml` |
| ViewModel | `ui/AuxDrillViewModel.kt` | своя логика фильтра и сессии |
| Экран | `ui/AuxDrillScreen.kt` | меню выбора пары + экран тренировки |
| Тайл | `ui/screens/HomeScreen.kt` | новый `AuxDrillEntryTile` рядом с `VerbDrillEntryTile` |
| Роут | `GrammarMateApp.kt` | `Routes.AUX_DRILL` + `composable` |
| Строки | `res/values/strings-app.xml`, `res/values-ru/strings-app.xml` | подписи |

### 2.3. Граница изоляции от регресса

Ни один новый класс не ссылается на `VerbDrillViewModel`, `VerbDrillStore`,
`VerbDrillComboProgress`, `VerbDrillUiState`. Единственный общий контакт —
чистые функции `LessonStore.getVerbDrillFiles` / `hasVerbDrill` и
`VerbDrillCsvParser.parse`. Изменение логики Verb Drill не заденет aux-режим, и
наоборот.

## 3. Каталог подводящих пар (MVP-состав)

Только служебные глаголы, опорный компонент которых **полностью покрыт** в пуле.
Модальные (dovere/potere/volere) и пассиво-формирователи (venire/andare) в MVP
**не входят** — их добавим позже отдельным шагом.

Каждая пара (глагол × время) → ведёт к уроку. Все пары покрыты в пуле
(35 карт на глагол в каждом времени: 7 лиц × 5 коллокаций).

| Aux-глагол | Время | Подводит к уроку | Тема урока |
|-----------|-------|------------------|------------|
| avere | Presente | B03 | Passato Prossimo con Avere |
| essere | Presente | B04 | Passato Prossimo con Essere |
| stare | Presente | B17 | Stare + gerundio |
| avere | Imperfetto | B06 | Trapassato Prossimo |
| essere | Imperfetto | B06 | Trapassato Prossimo |
| stare | Imperfetto | C12 | Stare + gerundio nel passato |
| avere | Futuro Semplice | B08 | Futuro Anteriore |
| essere | Futuro Semplice | B08 | Futuro Anteriore |
| avere | Condizionale Presente | B10 | Condizionale Composto |
| essere | Condizionale Presente | B10 | Condizionale Composto |
| avere | Congiuntivo Presente | B25 | Congiuntivo Presente |
| essere | Congiuntivo Presente | B26 | Congiuntivo Presente: irregolari |

**Уточнение по Congiuntivo:** обе пары подводят к урокам введения Congiuntivo
Presente (B25 — регулярные формы, B26 — неправильные). C01 Congiuntivo
Trapassato опирается на те же корни и может быть «следующим шагом», но в MVP
единственный урок-цель на пару — из колонки выше.

## 4. Поток работы пользователя

1. **Home** → тайл «Подводящие» рядом с «Глаголы».
2. **Экран Aux Drill** — список категорий (Настоящее / Прошедшее / Будущее /
   Условное / Сослагательное), внутри — пары (глагол → урок).
3. Ученик **выбирает пару** → запускается тренировка.
4. **Тренировка** — та же механика карточек, что в Verb Drill: ввод ответа,
   проверка, прогресс. Но в фокусе один опорный глагол.
5. Прогресс пишется в **свой** store, не смешивается с Verb Drill.
6. Назад → возврат на экран выбора.

## 5. Фильтрация пула

При выборе пары (verb, tense):
```
pool.filter { it.verb == selectedVerb && it.tense == selectedTense }
```
Для avere/essere/stare это ~35 карт (7 лиц × 5 коллокаций). Этого достаточно
для массовости. Сессия = `sessionSize` карт (по конфигу), добирается
перемешиванием или по rank (sortByFrequency) — повторяет логику Verb Drill.

## 6. Изоляция прогресса

- Файлы: `aux_drill_progress.yaml`, `aux_drill_last_session.yaml` (отдельные от
  `verb_drill_*`).
- ComboKey прогресса: `aux|<verb>|<tense>` — не пересекается с ключами Verb Drill.
- Для streak (PracticeType) в MVP **не учитывается** — aux-тренировка не даёт
  «огонька», чтобы не размывать дневные цели. (Опционально пересмотреть позже.)

## 7. Видимость кнопки

Тайл «Подводящие» показывается при том же условии `hasVerbDrill`, что и тайл
Verb Drill — т.к. питается тем же пулом. Отдельной проверки наличия aux-данных
не требуется.

## 8. Что НЕ входит в MVP (явные исключения)

- ❌ Модальные глаголы (dovere/potere/volere).
- ❌ Пассиво-формирователи (venire/andare) — парадигма есть, но без причастий
  полный пассив не собрать; отложено.
- ❌ Participio Passato / Gerundio / Infinito как самостоятельные времена —
  отсутствуют в пуле; новые данные не создаём.
- ❌ Подсветка/выделение формы опорного глагола в карточке.
- ❌ Учёт в PracticeType для streak.
- ❌ Привязка кнопки изнутри конкретного урока (выбор только свободный).

## 9. Риски и открытые вопросы

- **Дублирование логики сессии** (~200 строк) — принято как плата за изоляцию.
  При будущих изменениях надо держать оба слоя синхронно.
- **B25/B26/C01 разнесены** по урокам для одного Congiuntivo Presente — выбран
  один основной урок-цель на пару (см. §3).
- **Лексическая начинка** карточек (consapevole/capace/felice…) остаётся —
  ученик повторяет форму глагола, лексика не отвлекает (вариант B из обсуждения).

## 10. Критерии готовности MVP

- [ ] Тайл «Подводящие» появляется на Home при `hasVerbDrill`.
- [ ] Экран выбора показывает 5 категорий с парами и номерами уроков.
- [ ] Выбор пары запускает тренировку из карт пула по этому глаголу+времени.
- [ ] Прогресс сохраняется в `aux_drill_progress.yaml`, не влияет на Verb Drill.
- [ ] Существующий Verb Drill работает без изменений (регресс-тесты зелёные).
- [ ] Назад из тренировки возвращает на экран выбора.
