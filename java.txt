================================================================================
GRAMMARMATE (BASEGRAMMY) - JAVA SETUP AND APK BUILD INSTRUCTIONS
================================================================================

This file contains complete instructions for setting up a full JDK and building
the Android APK with the stock Gradle wrapper.

================================================================================
STOCK WRAPPER + FULL JDK (2026-10-05)
================================================================================

Use a full JDK with jlink. Local verified JDK: Corretto 21.0.8; CI uses JDK 17.
The bytecode target remains Java 17. The installed IntelliJ JBR lacks jlink
and cannot build this app.

Windows cmd:
  set JAVA_HOME=C:\Users\user\.jdks\corretto-21.0.8
  gradlew.bat :app:assembleDebug
  gradlew.bat :app:testDebugUnitTest :app:lintDebug --no-parallel --max-workers=1

Git Bash / Linux: ./gradlew (with JAVA_HOME set to your full JDK).
Both stock scripts load all three checked-in wrapper JARs. Direct Java invocation
is only a fallback, documented in section 3. Serial workers limit test JVM memory.

================================================================================
1. JAVA 17 INSTALLATION
================================================================================

OPTION A: Use the verified local JDK
-----------------------------------
  "C:\Users\user\.jdks\corretto-21.0.8\bin\java.exe" -version
  "C:\Users\user\.jdks\corretto-21.0.8\bin\jlink.exe" --version

OPTION B: Install standalone JDK
---------------------------------
Download and install JDK 17 (e.g., Eclipse Temurin from https://adoptium.net/)

Verify installation:
  java -version

Set JAVA_HOME environment variable to point to JDK installation directory.

================================================================================
2. ANDROID SDK SETUP (without Android Studio)
================================================================================

If Android Studio is not installed, set up SDK from command line.

2.1. Download command-line tools
----------------------------------
Download from: https://developer.android.com/studio#command-tools
(Section "Command line tools only")

2.2. Installation
------------------
Extract to a convenient directory, e.g., C:\Users\user\Android\Sdk\cmdline-tools\latest\

Install required components:
  sdkmanager --install "platforms;android-35" "build-tools;34.0.0" "platform-tools"

Accept licenses:
  sdkmanager --licenses

2.3. Configure local.properties
--------------------------------
Create file `local.properties` in project root with:

  sdk.dir=C:\\Users\\user\\Android\\Sdk

(Replace with your actual SDK path. This file is not committed to repo.)

Alternative: Set ANDROID_HOME environment variable:
  set ANDROID_HOME=C:\Users\user\Android\Sdk

================================================================================
3. STOCK GRADLE WRAPPER AND DIRECT JAVA FALLBACK
================================================================================

Use gradlew.bat on Windows or ./gradlew on Git Bash/Linux. Both scripts include:
  gradle/wrapper/gradle-wrapper.jar
  gradle/wrapper/gradle-wrapper-shared.jar
  gradle/wrapper/gradle-cli.jar

An older checkout with an incomplete classpath can fail with
NoClassDefFoundError: org/gradle/wrapper/IDownload. Update the wrapper scripts.
For diagnosis the equivalent direct command is:

  "C:\Users\user\.jdks\corretto-21.0.8\bin\java.exe" -cp "gradle/wrapper/gradle-wrapper.jar;gradle/wrapper/gradle-wrapper-shared.jar;gradle/wrapper/gradle-cli.jar" org.gradle.wrapper.GradleWrapperMain :app:assembleDebug

Use semicolons on a Windows JVM and colons on a Unix JVM. No build.bat helper
is required; set JAVA_HOME once and use the checked-in stock wrapper.

================================================================================
4. NON-CYRILLIC PROJECT PATH
================================================================================

If project directory contains non-Latin characters (e.g., "Разработка"),
Gradle may show path validation error.

File `gradle.properties` already contains:
  android.overridePathCheck=true

If missing, add this line to disable non-ASCII path check.

================================================================================
5. BUILD COMMANDS
================================================================================

DEBUG APK:
----------
build.bat assembleDebug

Output: app\build\outputs\apk\debug\grammermate.apk

RELEASE APK:
-----------
build.bat assembleRelease

RUN TESTS:
----------
build.bat test

Specific test class:
  build.bat test --tests "com.alexpo.grammermate.data.FlowerCalculatorTest"

Specific test method:
  build.bat test --tests "com.alexpo.grammermate.data.FlowerCalculatorTest.testBloomState"

CLEAN:
------
build.bat clean

================================================================================
TROUBLESHOOTING
================================================================================

Problem: 'java' command not found or java -version fails
Solution: Set JAVA_HOME to a full JDK with jlink, or use its full java.exe path
  "C:\Users\user\.jdks\corretto-21.0.8\bin\java.exe" -cp "gradle/wrapper/gradle-wrapper.jar;gradle/wrapper/gradle-wrapper-shared.jar;gradle/wrapper/gradle-cli.jar" org.gradle.wrapper.GradleWrapperMain assembleDebug

Problem: jlink executable does not exist
Solution: Use the full Corretto JDK configured above; the installed IntelliJ JBR
is insufficient. Confirm that JAVA_HOME/bin/jlink.exe exists.

Problem: NoClassDefFoundError: org/gradle/wrapper/IDownload
Solution: Ensure all three JARs are in classpath (see section 3 above)

Problem: Build fails despite correct Java setup
Solution: Check Android SDK path in local.properties and ensure API 35 is installed
